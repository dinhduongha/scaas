pqz-core: R_TX in the browser

Proves and verifies the bench statement of R_TX (seed = run number) with this machine's wasm32 build of pqz-core (build/wasm/pqz.wasm, served locally by artifact/reproduce.sh --serve), then verifies it with the generic verifier (pqz_verify) and the specialised one (pqz_verify_fast). The page runs on the main thread, so it freezes while it proves.
