**Invariant 2: no integer overflow in any limb / accumulator (L <= 54; C ceiling 56).**
- **Barrett** (`pqz_redx` / `redx`): (x >> (L-1))·MUX < 2^(2L+10) <= 2^128 for L <= 59, r < 3q < 2^63, and the masked subtractions are valid. Checked numerically at the extremes plus 200k random inputs.
- **red128 and modq_i64:** red128 has hi·R64 + lo < q² + 2^64 < 2^BARX. modq_i64's offset q·2^(63-L) < 2^63; its ceiling is R2-C1.

- **NTT algebra:** X^64+1 → X^32 ∓ i → X^16 ∓ ζ, X^16 ∓ ζ³ (ζ^6 = -i); the rho order is {ζ, -ζ, ζ³, -ζ³}; the inverse scales by 1/4. addq/subq/csubq inputs stay in [0, 2q). C = Rust line for line.

- **Norm sums:** two-limb l2sqr of centred coefficients stays < 2^121 even at n2816 txm16 (m1 = 550). The Gaussian decoder caps \|z\| at about 2^38. `binexp` uses only powers of two <= B, so the slack is < 2B² < q (`pqz_sv.c:1050`).
