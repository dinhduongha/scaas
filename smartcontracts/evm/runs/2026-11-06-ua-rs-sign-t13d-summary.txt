# __del__); close waits for calls in flight on that handle (a counter under a Condition), and a call on a closed handle raises ValueError
# without reaching the library. (6) Variable outputs: one call into a first buffer, again at the size asked for (a size query runs the call
# again; backup_seal's first buffer is 4 MiB so its generation rises once in practice); PqzKey.call always uses PQZ_OUT_MAX.
