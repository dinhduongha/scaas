# Decisions (controller, the owner may override): (1) The Rust-API bindings have no C ABI version: the bridge reports ABI_VERSION 6 (the
# surface generation, in step with SCAAS_UA_ABI_VERSION) and scaas_ua_features()'s bits from scaas_ua::build; the header's kAbiVersion and
# kRequiredFeatures are what it was written for. Refusal: Error("UAAbiMismatch", "abi_version" | "features") (a new code, binding-side only).
# The test hook is C++-side (detail::reportedAbiVersion / reportedFeatures, function pointers to the core by default), so a release library
# carries no hook of its own. (2) Secret inputs cross as &mut [u8] and are zeroized in Rust before the call returns, success or not, so the
# caller's Secret is all zero after it (the spec's "each binding zeroizes"); secret outputs are copied into a Secret and the bridge's buffer
# zeroed. A seal's plaintext and an AEAD key are not taken as secrets (not in spec §9.2's list). (3) Handles are rust::Box raw pointers in
# move-only classes (std::exchange on move; a moved-from handle throws UAArgument); liveHandles() counts the bridge's live handles for the
# "freed once" test. (4) Networks by their clientkeys names ("evm", ...), not numbers; members / accepted JSON "" = none; restore returns
# nullopt for "installed nothing"; rollback by its own name, over a wallet by restoreBackupOver. (5) One PQZ set per build (n2304-kmax4096,
# as ua-c's default); another set is a Cargo.toml change. (6) Key is Arc-shared and #[derive(ExternType)] so ua-qt can hold a handle (T13b).
# Notes: the panic guard of lib.rs maps a caught panic to "UAKeyData: internal" (unchanged from before T13a). No size query exists in this
# binding (every output is returned whole), so the PQZ bound is a constant checked against the facade's OUT_MAX at compile time and a test.
