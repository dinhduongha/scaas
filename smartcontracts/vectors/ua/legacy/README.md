  as they stood before the portable PoP (chain-bound `popDigest` over chain id, chain uid and registry; the
  `ref/pre-ua8` tag holds the same bytes). The live files carry the portable PoP (`portable.json`, UA-8 P1);
  `metatx3.json`, `uatrade_kat.json` and `ed25519_fuzz.json` hold no PoP and regenerated byte-identical, so they have no copy here.

  `pop-other-context` negatives); regenerated by `clients/ua-rs` `tests/groups.rs`. The chain-bound Rust functions stay in
  `clients/ua-rs/src/lib.rs` as `pop_digest_v1`, `holder_pop_message_v1`, `pqz_reg_message_v1`.
- KEM scheme byte (2026-10-30, owner, CTR-UA-32): `portable.json` as it stood before the scheme byte (1,600-byte `kemPk` =
  ML-KEM-1024 `ek` ‖ X25519 `pk`, no scheme byte), which the registry now refuses. The live file prefixes every KEM key with
  scheme 1 (`0x01 ‖ ek ‖ pk`, 1,601 B, the same key material) and adds four KEM-key negatives; only the KEM-derived fields moved.
- msig-pophash (2026-10-30, owner, CTR-UA-33): `msig-pophash/signatures.json` and `msig-pophash/pq_signatures.json` as they
  stood before every `msig` `MemberSig` carried an empty `keyData` (the classical members of `signatures.json` `msig.sets`
  and the p256 member of `pq_signatures.json` `msig.hybrid` carried their key data, which the registry now refuses: it
  reads a registered member's key from its record). The live files change only those `MemberSig` blobs (the same
  signatures) and add the negative set `derived-member-keydata`.
- webauthn-clients (2026-10-30, owner, CTR-UA-33 C): `webauthn-clients/signatures.json` as it stood before the eight
  `webauthn-p256` `abi-*` negatives (the canonical WebAuthn blob re-encoded off the canonical layout: trailing byte, each
  offset shifted, non-zero padding after each field, each length word beyond the data, fields swapped). The live file only
  appends those rows to `derived[0].negatives` (91 → 99 derived negatives).
- typed-signing (2026-10-31, owner: typed EIP-712 for the portable records, domain `EIP712Domain(string name,string version)`
