## Seam / khoảng trống
- Devnet: MyLocalTon không chạy (RAM chung); e2e chạy trên shim (TVM thật, block giả) — `TON_E2E_API` cho API thật.
- tx_id = hash external như đã gửi: nếu bên thứ ba phát lại bản bố cục khác (malleability, lý do TEP-467) thì
  `tx_status` không thấy tx ⇒ job `dead` khi hết hạn dù đã chạy; event `MetaTransactionExecuted` (theo `digest`) vẫn
  chốt op. Nâng cấp: tra thêm hash chuẩn hoá khi API thật hỗ trợ.
- TON Connect qua HTTP bridge/QR (cần `@tonconnect/sdk` vendored); nhiều passkey; `usedRefs` của Mandate chưa prune.
- MERGE (không sửa ở đây theo ruling): `lane_runner` chung (`adapter.rs`) không khôi phục job `signed`/`broadcast`
  sau khi node crash ⇒ payment request bị chặn qua `_live_job()`; sửa một lần ở nhánh tích hợp.
