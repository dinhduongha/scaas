## Global constraints (read before every task)

- AGENTS.md: `cargo` and `anvil` through `scripts/capped`, **foreground**, never inside `timeout`, never in the background; no
  `sleep` / `until` / `pgrep -f` loops; no background shell or `anvil` left behind (tests start and stop their own). The e2e step runs
  with `CAPPED_MEM=6G` and no other capped job of this agent beside it; everything else at the default 4 GB.
- Local only: the SDK's in-process fakes, `anvil`, a node built from this tree. Never the live testnet stack, its containers or its
  RPC port.
- TDD: write the test, run it, **see it fail for the stated reason**, implement, run it green. Every negative test has its positive
  control. Each task's mutants (listed) must each turn a named test red, one at a time, through
  `clients/scaas-tui/runs/2026-11-17-scaas-tui-t<n>-mutants.py` (the SDK plan's runner form: `(file, old, new, test command)`, modes
  `run` and `check`); the record `…-t<n>-mutants.txt` committed (last line `N mutants, N killed, 0 survived, 0 not loaded`).
- No logic below the view model (CLI-TUI-01): a task that seems to need a hash, a key, an HTTP call, a retry or a byte format stops
  and asks for it in the SDK. Every string from outside the TUI goes through `inert()` (CLI-TUI-05).
- `clippy::{unwrap_used, expect_used, panic, indexing_slicing}` denied in `src/`; no secret, form value or URL in a log line, error,
  `Debug` output or panic message.
- New files carry `// SPDX-License-Identifier: LicenseRef-Vegan-Community-1.0`. English. No consumer-specific name. No absolute or
  temp-directory path in a committed file; temp dirs by `mktemp -d` / `tempfile` at run time.
- Never edit a pin, a bound, a golden or a test to go green: a golden changes only with `SCAAS_TUI_BLESS=1` for a change the task
  states, and the diff is read before the commit.
- Gate logs: `clients/scaas-tui/runs/2026-11-17-scaas-tui-<step>.log` (git-ignored by `*.log`; first line `# <step> at commit <sha>`,
  last `rc=<n>`), progress lines on stdout (start, ok N/M, FAIL, a heartbeat every ~30 s); only
  `clients/scaas-tui/runs/2026-11-17-scaas-tui-summary.txt` (`step | commit | rc | counts`) committed. On resume read the logs
  first; a step done at the same commit on a clean tree is skipped.
