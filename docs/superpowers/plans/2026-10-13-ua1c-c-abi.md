**Goal:** A C ABI over the Rust UA crate (`clients/ua-rs`, crate `scaas-ua`). Its header is generated by cbindgen and
committed. Any language with a C FFI (C, Swift, Kotlin/JNI, Go cgo, Python ctypes, Zig, C# P/Invoke) can then use the
library without a port.

**Architecture:** A new crate `clients/ua-c` (`scaas-ua-c`, `crate-type = ["cdylib", "staticlib"]`) is a thin
`#[no_mangle] extern "C"` layer with the `scaas_ua_` prefix. It covers the same surface as `clients/ua-cxx/src/lib.rs`.
Every export runs inside one `catch_unwind` wrapper that returns an `int32_t` status and sets a thread-local error detail.
The header `clients/ua-c/include/scaas_ua.h` is generated by cbindgen and committed. A Rust test regenerates the header and
fails when the result differs from the committed bytes. Two non-Rust suites run the shared vectors:
- a Python `ctypes` suite (stdlib only), which runs every row;
- a C99 smoke test, built with `cc` and linked against the staticlib.

The bindings that already exist (`ua-cxx`, `ua-qt`, `ua-dart-frb`) are not changed.

## Rulings

- **U1C-1 Surface.** The C ABI covers exactly the `ua-cxx` bridge surface (and the "One API" list in ua-libraries.md):
  - the kind table and the closed sets;
  - `tag`, `kind_tag_string`, `group_tag`, `group_tag_string`, `msg_tag`, `purpose_tag`;
  - `ua_of`, `derive_ua`, `native_id`, `key_hash_of`, `validate_key_data`, `in_native_space`;
  - `ua_message`, `chain_key_hash`, `pop_digest`, `ua_auth_domain_separator`, `ua_auth_digest`, `member_digest`;
  - `canonical_id`, `encode_msig`.

  `verify` (and the signature vectors) is **not** exposed, because no other binding exposes it (cxx, Qt and FRB checked on
  2026-10-13). Add it when a binding needs it.
- **U1C-2 Caller-provided buffers, no Rust allocation crosses the ABI, no `scaas_ua_free`.**
  - Fixed-size inputs and outputs are `const uint8_t *` / `uint8_t *` of the documented size: 32 bytes, or 20 for
    `registry`. The doc comments, which cbindgen copies into the header, state the size.
  - Variable outputs (`kind_tag_string`, `group_tag_string`, `canonical_id`, `encode_msig`) take `(out, size_t *out_len)`.
    On entry `*out_len` is the capacity. On success it is the number of bytes written. When the buffer is too small the
    call returns `SCAAS_UA_ERR_BUFFER` and sets `*out_len` to the size needed, so `out = NULL, *out_len = 0` asks for the
    size.
  - Strings are written NUL-terminated, and `*out_len` counts the NUL.
- **U1C-3 Errors.** Every fallible export returns `ScaasUaStatus` (`int32_t`):

  | Value | Status |
  |---|---|
  | 0 | `SCAAS_UA_OK` |
  | 1 | `SCAAS_UA_ERR_KEY_DATA` (UAKeyData) |
  | 2 | `SCAAS_UA_ERR_ID_IN_NATIVE_SPACE` |
  | 3 | `SCAAS_UA_ERR_KIND_UNKNOWN` |
  | 4 | `SCAAS_UA_ERR_KIND_NOT_DERIVED` |
  | 5 | `SCAAS_UA_ERR_KIND_NOT_NATIVE` |
  | 6 | `SCAAS_UA_ERR_ID_FORMAT` |
  | 7 | `SCAAS_UA_ERR_PURPOSE_UNKNOWN` |
  | 8 | `SCAAS_UA_ERR_ARGUMENT` (UAArgument: NULL where a pointer is required, kind-table index out of range) |
  | 9 | `SCAAS_UA_ERR_BUFFER` |
  | 10 | `SCAAS_UA_ERR_INTERNAL` (a caught panic) |

  - `const char *scaas_ua_status_name(int32_t)` returns the static code string. It is `"UAKeyData"` and so on for statuses
    1–7, matching the vector files' `error` field.
  - `const char *scaas_ua_last_error(void)` returns a thread-local NUL-terminated detail: the `UAError` Display, e.g.
    `"UAKeyData: length"`. Every status-returning call sets it, and success sets it to `""`. The pointer stays valid until
    the next `scaas_ua_*` call on the same thread.
  - Non-UTF-8 text follows ua-cxx: a purpose gives `ERR_PURPOSE_UNKNOWN`, a canonical id gives `ERR_ID_FORMAT`, and a group
    is "unknown".
- **U1C-4 Optional results** (`key_hash_of` for structure kinds, `group_tag` / `group_tag_string` for an unknown group) are
  returned through a `bool *present` out-parameter with status `SCAAS_UA_OK`. They are not errors.
- **U1C-5 No unwinding across the ABI.** One generic `run(|| ...) -> ScaasUaStatus` wrapper puts every export inside
  `catch_unwind`. A panic gives `SCAAS_UA_ERR_INTERNAL`. Infallible exports that return a value (`kind_count`, `is_*`,
  `abi_version`) are also wrapped and return `0`/`false` on a panic. The crate sets no `panic = "abort"`.
- **U1C-6 Naming and ABI version.**
  - All symbols are `#[no_mangle] pub extern "C" fn scaas_ua_*`. Types are `ScaasUa*`. Constants are `SCAAS_UA_*`.
  - `uint32_t scaas_ua_abi_version(void)` returns `SCAAS_UA_ABI_VERSION` (= 1, also a header `#define`). The version is
    bumped on any breaking signature or layout change.
- **U1C-7 Kind table as a repr(C) struct with static pointers.** It has no free:
  `ScaasUaKind { uint16_t kind; bool native; uint8_t lengths_len; uint32_t lengths[2]; const char *name; const char *group; }`
  - `group == NULL` means no group, and `lengths_len == 0` means variable length.
  - `name` and `group` point into a process-lifetime `OnceLock` of `CString`s.
  - Accessors: `scaas_ua_kind_count()`, `scaas_ua_kind_at(index, out)`, `scaas_ua_kind_info(kind, out)`.
- **U1C-8 Flat parameters** for the domain (`generation`, `chain_id`, `registry[20]`, `chain_uid[32]`), as in ua-cxx. The
  only other struct is `ScaasUaMember { uint16_t kind; uint8_t id[32]; uint16_t weight; }` (36 bytes, align 2) for
  `encode_msig(threshold, members, n, out, out_len)`.
- **U1C-9 cbindgen as a pinned dev-dependency** (`cbindgen = { version = "=0.28.0", default-features = false }`). It is
  neither a build-dependency nor a separately installed tool.
  - `tests/header.rs` generates the header from `src/lib.rs` (`Builder::with_src`, so no `cargo metadata`) with
    `cbindgen.toml` and compares it byte for byte with `include/scaas_ua.h`.
  - `SCAAS_UA_C_BLESS=1 cargo test --test header` rewrites the header.
  - Consequences: `cargo build` of the library never needs cbindgen, and `Cargo.lock` pins it.
- **U1C-10 cbindgen.toml.** `language = "C"`, `cpp_compat = true` (an `extern "C"` guard, so C++/Swift/Zig consume the
  same header), `include_guard = "SCAAS_UA_H"`, `usize_is_size_t = true`, `style = "type"`, and the SPDX line plus "Generated
  by cbindgen 0.28.0, do not edit" in `header`.
- **U1C-11 Thread safety.** Every export is reentrant and safe from any thread: the library is pure computation over
  immutable static tables. The kind-table strings are initialised once (`OnceLock`), and `last_error` is per-thread. The
  header says so.
- **U1C-12 Tests.**
  - **Python ctypes** (`clients/ua-c/tests/test_vectors.py`, stdlib `unittest`) mirrors
    `clients/ua-cxx/tests/vectors_test.cpp` row for row: table/groups/purposes/constants, valid rows, invalid rows (codes
    via `status_name`), natives/nativeSpace/canonicalIds, messages, structures. It also covers the malformed-input and
    non-UTF-8 checks, buffer-too-small, and NULL arguments. It loads `target/debug/libscaas_ua_c.so`, with
    `SCAAS_UA_C_LIB` and `SCAAS_UA_VECTORS` as overrides.
  - **C smoke** (`clients/ua-c/tests/smoke.c`, C99, `-Wall -Wextra -Werror`) links `libscaas_ua_c.a` and checks:
    - `abi_version`;
    - one kind-table row;
    - one `derive_ua` against a hard-coded kinds.json row;
    - an error status plus `last_error`;
    - the buffer-size query.

    The header is also checked as C++ with `c++ -fsyntax-only -x c++ include/scaas_ua.h`.

## Spike findings

No ruling needed a change. Details the rulings left open, as implemented:

1. **cbindgen parse limit.** cbindgen 0.28.0 fails on a generic default in a type alias (`type R<T = ()> = ...`: "unsupported
   generic type default"), because it parses every item of `src/lib.rs`. The crate uses `type R<T> = Result<T, Fail>` and
   writes `R<()>`.
2. **`style = "type"`** (U1C-10) renders `typedef struct { ... } ScaasUaKind;`, an anonymous struct. The draft's interface
   sketch showed `typedef struct ScaasUaKind {...}` (style "both"). The ruling stands; the header in Task 1 is the
   interface.
3. **Status names outside 1–7:** `0` "UAOk", `8` "UAArgument", `9` "UABuffer", `10` "UAInternal", anything else
   "UAStatusUnknown".
4. **`last_error` details outside `UAError`:** "UAArgument: NULL", "UAArgument: index", "UABuffer: need <n>",
   "UAInternal: panic".
5. **Embedded NUL (Review Focus 3).** A `const char *` ends at its first NUL, so `"pop\0x"` is `"pop"`; no API taking a C
   string can see past it. The ctypes suite pins this (`test_embedded_nul_ends_the_string`). Non-UTF-8 text gives the
   ua-cxx codes.
6. **Pointers are checked where they are used.** An output that a call does not write may be NULL (e.g. `out32` of
   `group_tag` for an unknown group). When an optional result is present, `*present = true` is written before the
   output, so a size query on `group_tag_string` also reports presence. `write_var` sets `*out_len` to the size needed (or
   written) before checking the capacity and never writes `out` on `SCAAS_UA_ERR_BUFFER`.
7. **`status_name` and `last_error`** are wrapped like the other infallible exports (fallback `""`).
8. **Header text.** The ABI conventions and the thread-safety statement (U1C-11) are in `cbindgen.toml`'s `header`, so they
   head `scaas_ua.h`.
9. **Link line.** `cargo rustc --locked --lib --crate-type staticlib -- --print native-static-libs` prints
   `-lgcc_s -lutil -lrt -lpthread -lm -ldl -lc`. `-lpthread -ldl -lm` (the draft's line) links and runs with gcc 13.3 on
   Ubuntu 24.04 (the driver adds `-lgcc_s` and `-lc`; `util`/`rt` are in glibc 2.34+).
10. **Lockfile.** Do not use `cargo generate-lockfile`: it discards the seeded lock. Seed from ua-cxx and let `cargo build`
    extend it (Task 1 Step 1).

## Review Focus

1. A caller passes a buffer that is too small or NULL with capacity 0. Expected: `SCAAS_UA_ERR_BUFFER` with the size
   needed, never a write past `*out_len` (ctypes test with capacity 0, 1, needed−1).
2. A NULL pointer for a required input or output. Expected: `SCAAS_UA_ERR_ARGUMENT`, no crash. A NULL `key_data` with
   length 0 is a valid empty slice.
3. Non-UTF-8 text into `purpose_tag` / `canonical_id` / `group_tag`. Expected: the ua-cxx codes (U1C-3). Embedded NUL ends
   the C string (Spike finding 5).
4. `last_error` read on another thread, or after a later successful call. Expected: per-thread, and `""` after success
   (ctypes test with a `threading.Thread`).
5. The header drifts from `src/lib.rs` after an edit without a bless. Expected: `cargo test` fails with a diff hint
   (spike: a one-word doc-comment edit made `header_matches_src` fail with "include/scaas_ua.h drifted from src/lib.rs;
   regenerate with SCAAS_UA_C_BLESS=1 cargo test --locked --test header").

```rust
// SPDX-License-Identifier: LicenseRef-Vegan-Community-1.0
//! include/scaas_ua.h is generated from src/lib.rs and committed; this fails when they drift.
//! `SCAAS_UA_C_BLESS=1 cargo test --locked --test header` rewrites it.
use std::path::Path;

#[test]
fn header_matches_src() {
    let dir = Path::new(env!("CARGO_MANIFEST_DIR"));
    let config = cbindgen::Config::from_file(dir.join("cbindgen.toml")).unwrap();
    let mut generated = Vec::new();
    cbindgen::Builder::new()
        .with_config(config)
        .with_src(dir.join("src/lib.rs"))
        .generate()
        .unwrap()
        .write(&mut generated);
    let path = dir.join("include/scaas_ua.h");
    if std::env::var_os("SCAAS_UA_C_BLESS").is_some() {
        std::fs::write(&path, &generated).unwrap();
    }
    let committed = std::fs::read(&path).unwrap_or_default();
    assert!(
        committed == generated,
        "include/scaas_ua.h drifted from src/lib.rs; regenerate with SCAAS_UA_C_BLESS=1 cargo test --locked --test header"
    );
}
```

```rust
// SPDX-License-Identifier: LicenseRef-Vegan-Community-1.0
//! C ABI over `scaas-ua`; the header `include/scaas_ua.h` is generated from this file by cbindgen (tests/header.rs).
//! The caller owns every buffer, so no Rust allocation crosses the ABI. Every export runs inside `guard` (the one
//! `catch_unwind`): a panic never unwinds into C. Status-returning exports go through `run`, which also sets the
//! thread-local `scaas_ua_last_error` detail. UNAUDITED.
use scaas_ua as ua;
use std::cell::RefCell;
use std::ffi::{c_char, CStr, CString};
use std::panic::{catch_unwind, AssertUnwindSafe};
use std::sync::OnceLock;
use std::{ptr, slice};

/// Bumped on any breaking signature or layout change; compare with `scaas_ua_abi_version()`.
pub const SCAAS_UA_ABI_VERSION: u32 = 1;

/// The result of every fallible call: `SCAAS_UA_OK` or one of `SCAAS_UA_ERR_*`.
pub type ScaasUaStatus = i32;
pub const SCAAS_UA_OK: ScaasUaStatus = 0;
/// "UAKeyData": malformed key data, raw id or fixed-size input.
pub const SCAAS_UA_ERR_KEY_DATA: ScaasUaStatus = 1;
/// "UAIdInNativeSpace"
pub const SCAAS_UA_ERR_ID_IN_NATIVE_SPACE: ScaasUaStatus = 2;
/// "UAKindUnknown"
pub const SCAAS_UA_ERR_KIND_UNKNOWN: ScaasUaStatus = 3;
/// "UAKindNotDerived"
pub const SCAAS_UA_ERR_KIND_NOT_DERIVED: ScaasUaStatus = 4;
/// "UAKindNotNative"
pub const SCAAS_UA_ERR_KIND_NOT_NATIVE: ScaasUaStatus = 5;
/// "UAIdFormat"
pub const SCAAS_UA_ERR_ID_FORMAT: ScaasUaStatus = 6;
/// "UAPurposeUnknown"
pub const SCAAS_UA_ERR_PURPOSE_UNKNOWN: ScaasUaStatus = 7;
/// "UAArgument": NULL where a pointer is required, or a kind-table index out of range.
pub const SCAAS_UA_ERR_ARGUMENT: ScaasUaStatus = 8;
/// "UABuffer": `*out_len` was too small; it now holds the size needed.
pub const SCAAS_UA_ERR_BUFFER: ScaasUaStatus = 9;
/// "UAInternal": a caught panic (a bug).
pub const SCAAS_UA_ERR_INTERNAL: ScaasUaStatus = 10;

/// One row of the kind table. `name` and `group` are static NUL-terminated strings (never freed); `group` is NULL when
/// the kind has no group. `lengths[0..lengths_len]` are the accepted key-data lengths; `lengths_len == 0` means variable
/// length.
#[repr(C)]
pub struct ScaasUaKind {
    pub kind: u16,
    pub native: bool,
    pub lengths_len: u8,
    pub lengths: [u32; 2],
    pub name: *const c_char,
    pub group: *const c_char,
}

/// One `msig` member: `id` is the member's 32-byte UA.
#[repr(C)]
pub struct ScaasUaMember {
    pub kind: u16,
    pub id: [u8; 32],
    pub weight: u16,
}

struct Fail(ScaasUaStatus, String);
type R<T> = Result<T, Fail>;

impl From<ua::UAError> for Fail {
    fn from(e: ua::UAError) -> Self {
        use ua::UAError::*;
        let status = match e {
            KeyData(_) => SCAAS_UA_ERR_KEY_DATA,
            IdInNativeSpace => SCAAS_UA_ERR_ID_IN_NATIVE_SPACE,
            KindUnknown(_) => SCAAS_UA_ERR_KIND_UNKNOWN,
            KindNotDerived(_) => SCAAS_UA_ERR_KIND_NOT_DERIVED,
            KindNotNative(_) => SCAAS_UA_ERR_KIND_NOT_NATIVE,
            IdFormat => SCAAS_UA_ERR_ID_FORMAT,
            PurposeUnknown => SCAAS_UA_ERR_PURPOSE_UNKNOWN,
        };
        Fail(status, e.to_string())
    }
}
fn argument(what: &str) -> Fail {
    Fail(SCAAS_UA_ERR_ARGUMENT, format!("UAArgument: {what}"))
}

thread_local! {
    static LAST_ERROR: RefCell<CString> = RefCell::new(CString::default());
}

/// The one `catch_unwind`: a panic becomes `SCAAS_UA_ERR_INTERNAL`.
fn guard<T>(f: impl FnOnce() -> R<T>) -> R<T> {
    catch_unwind(AssertUnwindSafe(f)).unwrap_or_else(|_| Err(Fail(SCAAS_UA_ERR_INTERNAL, "UAInternal: panic".into())))
}
/// A status-returning export: the status, with the detail ("" on success) stored for `scaas_ua_last_error`.
fn run(f: impl FnOnce() -> R<()>) -> ScaasUaStatus {
    let (status, detail) = match guard(f) {
        Ok(()) => (SCAAS_UA_OK, String::new()),
        Err(Fail(status, detail)) => (status, detail),
    };
    let _ = LAST_ERROR.try_with(|e| *e.borrow_mut() = CString::new(detail).unwrap_or_default());
    status
}
/// An infallible export: `fallback` on a panic.
fn safe<T>(fallback: T, f: impl FnOnce() -> T) -> T {
    guard(|| Ok(f())).unwrap_or(fallback)
}

fn arr<'a, const N: usize>(p: *const u8) -> R<&'a [u8; N]> {
    if p.is_null() {
        return Err(argument("NULL"));
    }
    Ok(unsafe { &*p.cast::<[u8; N]>() })
}
/// `len` items at `p`; NULL with `len == 0` is the empty slice.
fn bytes<'a, T>(p: *const T, len: usize) -> R<&'a [T]> {
    if len == 0 {
        return Ok(&[]);
    }
    if p.is_null() {
        return Err(argument("NULL"));
    }
    Ok(unsafe { slice::from_raw_parts(p, len) })
}
fn put<T>(p: *mut T, value: T) -> R<()> {
    if p.is_null() {
        return Err(argument("NULL"));
    }
    unsafe { p.write(value) };
    Ok(())
}
/// The bytes of a NUL-terminated string; the caller decodes them as UTF-8 and maps a failure per call.
fn cstr<'a>(p: *const c_char) -> R<&'a [u8]> {
    if p.is_null() {
        return Err(argument("NULL"));
    }
    Ok(unsafe { CStr::from_ptr(p) }.to_bytes())
}
/// Variable-size output: `*out_len` is the capacity on entry and the size written (or needed) on return.
fn write_var(out: *mut u8, out_len: *mut usize, b: &[u8]) -> R<()> {
    if out_len.is_null() {
        return Err(argument("NULL"));
    }
    let cap = unsafe { out_len.replace(b.len()) };
    if cap < b.len() {
        return Err(Fail(SCAAS_UA_ERR_BUFFER, format!("UABuffer: need {}", b.len())));
    }
    if out.is_null() {
        return Err(argument("NULL"));
    }
    unsafe { ptr::copy_nonoverlapping(b.as_ptr(), out, b.len()) };
    Ok(())
}
/// `s` NUL-terminated; `*out_len` counts the NUL.
fn write_str(out: *mut c_char, out_len: *mut usize, s: &str) -> R<()> {
    write_var(out.cast(), out_len, CString::new(s).unwrap_or_default().as_bytes_with_nul())
}

fn kind_row(i: usize) -> ScaasUaKind {
    static STRINGS: OnceLock<Vec<(CString, Option<CString>)>> = OnceLock::new();
    let c = |s: &str| CString::new(s).unwrap();
    let strings = STRINGS.get_or_init(|| ua::KINDS.iter().map(|k| (c(k.name), k.group.map(c))).collect());
    let k = &ua::KINDS[i];
    let mut lengths = [0u32; 2];
    for (n, l) in k.lengths.iter().enumerate() {
        lengths[n] = *l as u32; // ponytail: panics (UAInternal) if a kind ever gets more than two lengths
    }
    ScaasUaKind {
        kind: k.kind,
        native: k.native,
        lengths_len: k.lengths.len() as u8,
        lengths,
        name: strings[i].0.as_ptr(),
        group: strings[i].1.as_ref().map_or(ptr::null(), |g| g.as_ptr()),
    }
}
```

```python
class UAErr(Exception):
    def __init__(self, status):
        self.status, self.code, self.detail = status, L.status_name(status).decode(), L.last_error().decode()

def ok(status):
    if status != OK:
        raise UAErr(status)


def out32(fn, *args):
    buf = C.create_string_buffer(32)
    ok(fn(*args, buf))
    return buf.raw


def var(fn, *args):
    """A variable output: ask for the size, then fetch."""
    n = sz(0)
    status = fn(*args, None, C.byref(n))
    if status != ERR_BUFFER:
        ok(status)
    buf = C.create_string_buffer(n.value)
    ok(fn(*args, buf, C.byref(n)))
    return buf.raw[:n.value]


def text(fn, *args):
    return var(fn, *args)[:-1].decode()  # *out_len counts the NUL


def opt32(fn, *args):
    buf, present = C.create_string_buffer(32), bl()
    ok(fn(*args, buf, C.byref(present)))
    return buf.raw if present.value else None


def opt_text(fn, g):
    n, present = sz(0), bl()
    status = fn(g, None, C.byref(n), C.byref(present))
    if not present.value:
        ok(status)
        return None
    buf = C.create_string_buffer(n.value)
    ok(fn(g, buf, C.byref(n), C.byref(present)))
    return buf.raw[:n.value - 1].decode()
```
