# S11 Aptos — kế hoạch thực hiện

**Mục tiêu:** sáu deliverable của "Network streams — shared contract" cho Aptos. **Thiết kế:**
`docs/superpowers/specs/2026-10-04-net-aptos.md` (bản nháp: scratchpad `net-aptos-spec.md`). **Kiến trúc:** Move
package `chains/aptos` (auth/meta/mandate/dex) → adapter Rust `adapters/aptos.rs` (REST fullnode, BCS tự dựng) → Odoo
`fam_aptos` (payload + verify) → connector Wallet Standard AIP-62. **Stack:** Aptos CLI (`~/.local/bin/aptos`, bản
ghim ở Task 0), Rust (bamboo-node), Odoo 19 (`dms_test_chain_11`/8931), Node.
**Nhánh:** `r3-aptos` từ đỉnh nhánh tích hợp. **Sở hữu:** `chains/aptos/**`, `bamboo-node/src/adapters/aptos.rs`,
`bamboo-node/tests/e2e_aptos.rs`, `dms_blockchain/lib/fam_aptos.py`, `dms_blockchain/models/blockchain_aptos.py`,
`dms_blockchain/tests/test_fam_aptos.py`, `connectors/aptos.js` + `static/tests/connectors/aptos.test.mjs`.
**Cổng:** Odoo 8931, devnet REST 32010 / faucet 32011 / ready 32012 (32013–32019 dự phòng). Một devnet mỗi lúc;
`free -g` trước mọi bước nặng; không chạy song song với merge/build nặng của luồng khác.

Biến dùng trong lệnh kiểm: `WT=<worktree r3-aptos>`, `SP=<scratch của luồng>`.

- [ ] Đọc `aptos node run-localnet --help`: cờ cổng REST/faucet/ready; không có cờ REST ⇒ ghi cách sửa `api.address`
  trong config node sinh ra ở `--test-dir` (spec §9).
- Kiểm: `aptos --version`; `/usr/bin/grep -n '637' $WT/bamboo-node/src/keys.rs`;
  `cargo test --manifest-path $WT/bamboo-node/Cargo.toml keys::` (vector đường 637 của lead xanh).

## Task 2 — Move package (TDD)
- [ ] `Move.toml` (`bamboo = "_"`, dev-address, AptosFramework ghim rev `mainnet`).
- [ ] `auth`: `check_envelope` (parse chặt §4.2), `ed25519::signature_verify_strict`, auth key legacy/SingleKey.
  Test đỏ trước: hai dòng `message`, khoá lạ, khoá lặp, `chainId` sai, thứ tự dòng khác vẫn qua.
- [ ] `meta`: `Root`, `Account` derived, mở lười + `open`, `relay_pay`, ba đường quản trị + guardian/trễ, `prune`,
  event. Test: replay, hạn, sai miền (chain/contract/asset/op), relayer, khoá ≠ auth key bị từ chối, stateless mở được,
  không xoá khoá cuối, rotate auth key native không ảnh hưởng.
- [ ] `mandate`: `open` ký bởi khoá Account, cấp vốn bằng `pay`, trần lần/kỳ (phép trừ), payee, `pay_ref` một lần +
  prune, revoke/close về Account.
- [ ] `dex`: `Market` derived mỗi cặp, `settle` (giá chéo u128, `filled`, FOK/IOC, phí ≤ `max_fee_ppm`, trần 1 %),
  `cancel_signed`, `invalidate_nonces_signed` theo market, `sweep`.
- [ ] `scripts/gen_vectors.py` → `tests/vectors.move` (payload 310 B, digest, phong bì, chữ ký thật, địa chỉ derived).
- [ ] **Anti-lock:** X (pay tài sản A) giữ, Y (mandate pay / DEX cancel) qua, X qua sau; cùng Account hai tài sản hai
  lane. **Anti-lock coin:** FA gửi thẳng tới Account (trước/sau khi tồn tại), Mandate, Market (`sweep`), coin cũ có FA
  cặp tới Account.
- [ ] Kiểm dispatchable FA đi qua `primary_fungible_store::transfer` (một test với FA có hook) — ghi kết quả vào spec.
- Kiểm: `aptos move test --package-dir $WT/chains/aptos --dev` (0 lỗi, ghi số test);
  `python3 $WT/chains/aptos/scripts/gen_vectors.py --check` (vector đã commit = vector sinh lại).
