## Global constraints (read before every task)

- AGENTS.md: `cargo`, `anvil`, `forge` through `scripts/capped`, **foreground**, never inside `timeout`, never in the background;
  no `sleep` / `until` / `pgrep -f` loops; no background shell or `anvil` left behind (tests start and stop their own). **The whole
  node suite needs 6 GB, alone:** `CAPPED_MEM=6G`, and no other capped job of this agent beside it. Everything else at the default
  4 GB. Docker (the local Nethermind of T0, family local networks) with `--memory` set.
- Inputs as real directories in this worktree: `smartcontracts/evm/lib` (`scripts/evm_libs.sh install`, then `check`) before the
  node e2e or a verifier anvil test.
- Local chains only: `anvil`, a local Nethermind dev chain, the families' local networks via `devnet.sh`. Never the live testnet
  stack, its containers or its RPC port.
- TDD in every task: write the test, run it, **see it fail for the stated reason**, implement, run it green. A negative test has its
  positive control beside it. Each task's mutants (listed; "no behaviour change" tasks included, F17) must each turn a named test
  red, one at a time, through `clients/scaas-rpc/runs/2026-11-17-scaas-rpc-t<n>-mutants.py` (a list of `(file, old, new, test
  command)`, modes `run` and `check`); record `…-t<n>-mutants.txt` committed (last line `N mutants, N killed, 0 survived, 0 not
  loaded`).
- **No behaviour change where a task says so:** the counts of passed / ignored tests of every gate the task names equal T0's
  baseline plus the task's new tests; no existing test is deleted or renamed; the task's intended differences are listed in its
  commit message. Never edit a pin, a bound or a test to go green; a red stops the task and is reported with its output.
- Every new input bounded (CLI-RPC-07); every HTTP client built with `redirect(Policy::none())` (F8); a credential only to its own
  endpoint; no URL, body, header or secret in a log line or error (CLI-RPC-11); no consumer-specific name in the crate or the node
  (comments reworded on a move, F26); no `tokio::time` in the crate (F18).
- New source files carry `// SPDX-License-Identifier: LicenseRef-Vegan-Community-1.0`. Code, comments, commits in English.
  Existing Vietnamese comments in moved code stay as they are.
- No absolute or `/tmp` path in a committed file; temp dirs by `mktemp -d` at run time.
- Gate logs: `clients/scaas-rpc/runs/2026-11-17-scaas-rpc-<step>.log` (git-ignored by `*.log`; first line `# <step> at commit <sha>`,
  last `rc=<n>`), progress lines on stdout (start, ok N/M, FAIL, a heartbeat every ~30 s). Only
  `clients/scaas-rpc/runs/2026-11-17-scaas-rpc-summary.txt` (`step | commit | rc | counts`) is committed. On resume read the logs
  first; a step done at the same commit on a clean tree is skipped.
