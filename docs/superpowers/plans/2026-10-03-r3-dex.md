# R3 S5 — DEX (R35) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [x]`) syntax.

**Goal:** off-chain persistent order book + on-chain settlement (`OrderBookDex`), gasless approve, Odoo addon.

**Architecture:** `docs/superpowers/specs/2026-10-03-dex-design.md`. Contract settles signed orders with partial fills;
node keeps a price-time book persisted in Odoo (`/json/2`), settles through the outbox as `call` jobs, ingests final
DEX events with its own cursor; Odoo stores markets/orders/trades and books fees.

**Tech:** Solidity 0.8.28 + forge; Rust (alloy 1.6, axum 0.8); Odoo 19.

Branch `r3-dex`; Odoo DB `dms_test_chain_5` port 8925; anvil 31950–31959; gateway 18650–18659.
