# S12 Solana — kế hoạch thực hiện

**Mục tiêu:** sáu deliverable của "Network streams — shared contract" cho Solana. **Thiết kế:**
`docs/superpowers/specs/2026-10-04-net-solana.md` (bản nháp: scratchpad `net-solana-spec.md`). **Kiến trúc:** program
Anchor `chains/solana` (auth introspection / account+pay / mandate / dex) → adapter Rust `adapters/solana.rs` (JSON-RPC,
tx v1 viết tay, durable nonce mỗi lane) → Odoo `fam_solana` (payload + PDA + verify) → connector Wallet Standard
(`solana:signOffchainMessage` / `solana:signMessage`). **Stack:** Agave CLI + platform-tools (`cargo build-sbf`), Anchor
1.x (crate, không cần CLI), LiteSVM, Rust (bamboo-node), Odoo 19 (`dms_test_chain_12`/8932), Node (`@solana/kit` chỉ để
sinh vector).
**Nhánh:** `r3-solana` từ đỉnh nhánh tích hợp (sau S11). **Sở hữu:** `chains/solana/**`,
`bamboo-node/src/adapters/solana.rs`, `bamboo-node/tests/e2e_solana.rs`, `dms_blockchain/lib/fam_solana.py`,
`dms_blockchain/models/blockchain_solana.py`, `dms_blockchain/tests/test_fam_solana.py`, `connectors/solana.js` +
`static/tests/connectors/solana.test.mjs`.
**Cổng:** Odoo 8932, validator RPC 32020 / WS 32021 / faucet 32022 / gossip 32023 / dynamic 32024–32029. Một validator mỗi
lúc; `free -g` trước mọi bước nặng; `CARGO_BUILD_JOBS=2` cho `cargo build-sbf`; không build song song với S11.

Biến dùng trong lệnh kiểm: `WT=<worktree r3-solana>`, `SP=<scratch của luồng>`, `PATH` có
`~/.local/share/solana/install/active_release/bin`.

## Task 0 — Tiền đề

- [ ] Commit tiên quyết của lead đã có (spec §12): `Family::Solana` (+ sửa test `families_parse`), `lane_path("solana")`,
  `uses_adapter`/`validate`, Odoo `FAMILIES` + `addresses.canonical('solana')`, ingest nhận `tx_hash` 64 byte cho
  `solana`. Chưa có ⇒ dừng, báo coordinator, không tự sửa.
- [ ] Cài Agave (bản ổn định mới nhất có tx v1 — Agave ≥ 4.2) bằng installer chính thức vào thư mục người dùng (không
  sudo); `cargo build-sbf --version` tải platform-tools. Ghi phiên bản vào spec.
- [ ] Chốt phiên bản `anchor-lang`/`anchor-spl` 1.x và `litesvm`; kiểm LiteSVM có precompile secp256r1 (một test nhỏ),
  ghi kết quả (không có ⇒ test passkey chuyển sang e2e, spec §9).
- [ ] Đọc `solana-test-validator --help`: cờ cổng, độ rộng tối thiểu `--dynamic-port-range` (không đủ 6 ⇒ OQ4 cho
  coordinator, tạm dùng dải coordinator cấp).
- [ ] Khởi động validator một lần (cổng S12), `solana feature status` xác nhận secp256r1 + tx v1 đang bật; tắt.
- [ ] `npm i @solana/kit` cục bộ trong `chains/solana/scripts/` (không commit `node_modules`); ghim bố cục OCMS v1 và

- Kiểm: `solana --version`; `cargo build-sbf --version`; `/usr/bin/grep -n "501" $WT/bamboo-node/src/keys.rs`;

  `pgrep -f solana-test-validator` rỗng sau khi tắt.

## Task 2 — Program Anchor (TDD, LiteSVM)
- [ ] Workspace `chains/solana/` (Cargo riêng, `programs/bamboo`, `tests/` LiteSVM), `Anchor.toml` tối thiểu cho program
  id; keypair program dev trong `chains/solana/keys/` (chỉ dev, ghi rõ).
- [ ] `auth`: dựng `MetaOp`/`T`/OCMS, introspection precompile (§4.3), WebAuthn (§4.2). Test đỏ trước: instruction index
  ≠ `u16::MAX`, sai program precompile, message lệch một byte, pk ∉ keys, OCMS signer khác, high-S, thiếu UV, origin lạ.
- [ ] `account`: `initialize` (chỉ upgrade authority), `open`/`open_passkey`, `relay_pay` (mở lười, `create_idempotent`
  ATA đích, `transfer_checked`, chính sách Token-2022 §3.6, `emit_cpi!`), `manage_signed` (mọi action + add_origin cùng
  rpId + `set_policy`), recovery, `withdraw_lamports`, `prune`.
- [ ] `mandate`: open bằng chữ ký khoá Account, pay (trần lần/kỳ bằng phép trừ, payee, `mref` một lần), revoke/close về
  Account.
- [ ] `dex`: `list_market`/`set_market` (trần 10 000 ppm), `settle` nhiều cặp (giá chéo u128, `Fill`, FOK/IOC, phí ≤
  `max_fee_ppm`), `cancel_signed` (kể cả lệnh chưa khớp), `invalidate_nonces_signed`, `sweep`.
- [ ] `scripts/gen_vectors.py` → `programs/bamboo/tests/vectors.rs` (payload 336 B, digest, `T`, OCMS, chữ ký thật, PDA
  account/lane/mandate/fill, ATA cả hai token program).
- [ ] **Anti-lock:** X (pay tài sản A) giữ, Y (`mandate_pay` / `cancel_signed`) qua, X qua sau; cùng Account hai tài sản
  hai lane. **Write-set:** writable(X) ∩ writable(Y) ⊆ {lane, nonce lane}; Config/Market/SubjectAccount readonly.
  **Anti-lock coin:** SPL tới ATA Account trước/sau khi tồn tại, tới token account phụ của PDA, tới Mandate, `sweep`
  Market, lamports ⇒ `withdraw_lamports`.
- Kiểm: `free -g`; `CARGO_BUILD_JOBS=2 cargo build-sbf --manifest-path $WT/chains/solana/programs/bamboo/Cargo.toml`;
  `cargo test --manifest-path $WT/chains/solana/Cargo.toml` (0 lỗi, ghi số test);
  `python3 $WT/chains/solana/scripts/gen_vectors.py --check` (vector đã commit = vector sinh lại).

## Task 4 — Adapter Rust

  ký lane, kiểm `getGenesisHash` = `Config.network` = `network` lúc khởi tạo, nonce account tự tạo, `sequence` = nonce,
  simulate (`sigVerify:false`), CU + priority fee, `submit` + bảng `Rejected`, rebroadcast trong `tx_status`, phân loại
