## Review Focus

- **Panics and exceptions at the FFI boundary**: a Rust panic must never unwind into C++, the Qt event loop or the Dart VM;
  a C++ caller passing a wrong-length array, or QML passing odd-length / `0X` / non-hex strings, gets an error code, never
  a crash. Each task's test includes a malformed-input case.
- **Undecodable key data is `UAKeyData` in every binding** (QML maps hex-decoding failures of key data and native ids to
  `UAKeyData`; `UAArgument` is reserved for digests, ids, purposes, chain ids and JSON).
- **64-bit chain ids**: QML numbers and dart2js ints are exact only to 2^53, FRB maps `u64` to `BigInt`, C++ uses
  `uint64_t`; structures.json context E (2^40 + 7) passes in all four; the limits are documented.
- **Version skew**: FRB crate ≠ codegen ≠ pub, or `cxx-gen` ≠ `cxx`, breaks at build or link time — the pins are exact and
  the CI jobs install the pinned codegen.
- **Library and vector discovery in tests**: each suite finds the native library and the vectors by a documented default
  path with an environment override, so CI and developers run the same command.

## Rulings (docs vs code) and defaults taken

- **B1 Layers (owner 2026-10-12):** C++ as two layers — a plain `cxx` bridge for non-Qt C++ and CXX-Qt for QML — and Dart
  as both flutter_rust_bridge v2 and a pure-Dart port. Directories `clients/scaas-ua-cxx`, `clients/scaas-ua-qt`,
  `clients/scaas-ua-frb`, `clients/ua-dart`.
- **B2 Build of the plain C++ layer:** CMake runs `cargo build --release --locked` and imports the staticlib (no
  Corrosion: only the staticlib and the cxx-generated header are needed). The CXX-Qt layer follows the cxx-qt book
  (cxx-qt-cmake 0.9.1, which fetches Corrosion v0.5.2).
- **B3 CXX-Qt package name:** the Cargo package is `scaas_ua_qt` (underscores) in directory `scaas-ua-qt` — cxx-qt-cmake's
  exported crate variable does not match a hyphenated name and the link fails. `cxx-gen` is pinned `=0.7.202` because
  cxx-qt-build floats it and a newer cxx-gen than `cxx` gives undefined symbols.
- **B4 QML API:** byte values are `"0x…"` hex strings (input also accepted without `0x`), `kindInfo` returns a JSON string,
  `encodeMsig` takes a JSON array string; failure returns `""` / `false` and sets `lastError` (cleared at the start of
  every call, NOTIFY `lastErrorChanged`); the reason text does not reach QML. Undecodable key data → `UAKeyData`; other
  undecodable arguments → `UAArgument` (a QML-binding code); a caught panic → `UAInternal`.
- **B5 FRB API:** all functions `#[frb(sync)]`; fixed-size values are `[u8; 32]` / `[u8; 20]` (Dart `U8Array32` /
  `U8Array20`: a wrong length is a compile error); `u64` → `BigInt`; `UAError {code, reason}` implements `FrbException`.
  The generated files (`rust/src/frb_generated.rs`, `lib/src/rust/**`) are produced by the pinned codegen in the task and
  committed — the plan does not inline ~108 KB of generated code.
- **B6 FRB targets:** this plan builds and tests the Linux native library only (pure Dart package, no Flutter needed).
  Flutter plugin packaging (cargokit), Android (NDK), iOS/macOS (Xcode) and the web build (`build-web`: nightly Rust,
  wasm-bindgen-cli 0.2.129, COOP/COEP headers) are documented, not built; whether `scaas-ua` compiles to wasm is open.
- **B7 Pure-Dart port:** in-package Keccak-f[1600] (64-bit lanes as 32-bit halves, exact under dart2js) — no dependency;
  BigInt affine arithmetic like the C# port; key data accepted as `Uint8List` or hex string, else `UAKeyData` ('type' /
  'hex'); chain ids are `int` (exact to 2^53 under JS).
- **B8 cxx constants:** `DOMAIN_TYPEHASH`, `UAAUTH_TYPEHASH`, `NAME_HASH` are not exposed (no keccak in the API); the
  domain-separator and UAAuth digest tests cover them.

//! cxx bridge over `scaas-ua`. Byte data crosses as `&[u8]` / `Vec<u8>`; fixed-size inputs are length-checked here, so a
//! malformed call is an `Err` (thrown as `rust::Error` in C++), never UB. Fallible calls return `Result`; the message is
//! `UAError`'s Display (`"<code>"` or `"UAKeyData: <reason>"`), which `include/scaas_ua.hpp` turns into code + reason.
use scaas_ua as ua;
use std::panic::{catch_unwind, AssertUnwindSafe};

pub struct UaErr(String);
impl core::fmt::Display for UaErr {
    fn fmt(&self, f: &mut core::fmt::Formatter<'_>) -> core::fmt::Result {
        f.write_str(&self.0)
    }
}
impl From<ua::UAError> for UaErr {
    fn from(e: ua::UAError) -> Self {
        UaErr(e.to_string())
    }
}
type R<T> = Result<T, UaErr>;

/// Run `f`, turning a (never expected) panic into an error instead of unwinding into C++.
fn guard<T>(f: impl FnOnce() -> R<T>) -> R<T> {
    catch_unwind(AssertUnwindSafe(f)).unwrap_or_else(|_| Err(UaErr("UAKeyData: internal".into())))
}
fn a<const N: usize>(b: &[u8]) -> R<[u8; N]> {
    b.try_into().map_err(|_| UaErr("UAKeyData: length".into()))
}

#include <optional>
#include <stdexcept>

namespace scaas::ua {

using Bytes = std::vector<uint8_t>;

// code(): UAKeyData, UAIdInNativeSpace, UAKindUnknown, UAKindNotDerived, UAKindNotNative, UAIdFormat, UAPurposeUnknown.
// reason(): the label after "UAKeyData: " (empty for every other code).
class Error : public std::runtime_error {
public:
    Error(std::string code, std::string reason)
        : std::runtime_error(reason.empty() ? code : code + ": " + reason), code_(std::move(code)), reason_(std::move(reason)) {}
    const std::string& code() const noexcept { return code_; }
    const std::string& reason() const noexcept { return reason_; }

private:
    std::string code_, reason_;
};

struct KindInfo {
    uint16_t kind;
    std::string name;
    bool native;
    std::vector<size_t> lengths;  // empty = variable length
    std::optional<std::string> group;
};
struct Member {
    uint16_t kind;
    Bytes id;  // 32 bytes
    uint16_t weight;
};
struct Domain {
    uint32_t generation;
    uint64_t chainId;
    Bytes registry;  // 20 bytes
    Bytes chainUid;  // 32 bytes

    return p == std::string::npos ? Error(m, "") : Error(m.substr(0, p), m.substr(p + 2));
}
template <class F>
auto call(F&& f) -> decltype(f()) {
    try {
        return f();
    } catch (const rust::Error& e) {
        throw translate(e);
    }
}

    if (v.empty()) return std::nullopt;
    return bytes(v);
}

    return {k.kind, std::string(k.name), k.native, std::vector<size_t>(k.lengths.begin(), k.lengths.end()),
            k.has_group ? std::optional<std::string>(std::string(k.group)) : std::nullopt};
}
ffi::Member conv(const Member& m) {
    rust::Vec<uint8_t> id;
    for (auto b : m.id) id.push_back(b);
    return {m.kind, std::move(id), m.weight};
}

    return out;
}

    do {                                                                                   \

static Bytes bytes(const json& v) {
    std::string h = v.get<std::string>();
    if (h.rfind("0x", 0) == 0) h = h.substr(2);
    Bytes out;
    for (size_t i = 0; i + 1 < h.size(); i += 2) out.push_back(uint8_t(std::stoi(h.substr(i, 2), nullptr, 16)));
    return out;
}
static std::string hx(const Bytes& b) {
    static const char* d = "0123456789abcdef";

    for (auto c : b) { s += d[c >> 4]; s += d[c & 15]; }
    return s;
}

static void table_groups_purposes_constants() {
    json k = load("kinds.json");
    auto table = kinds();
    CHECK(k["kinds"].size() == table.size(), "table size");
    for (auto& r : k["kinds"]) {
        uint16_t n = kind(r["kind"]);
        auto info = kindInfo(n);
        std::string name = info.name;
        CHECK(info.name == r["name"].get<std::string>(), name);
        CHECK(info.native == r["native"].get<bool>(), name);
        CHECK(info.lengths == r["lengths"].get<std::vector<size_t>>(), name);
        CHECK(info.group.has_value() == !r["group"].is_null(), name);

        CHECK(isZether(n) == r["zether"].get<bool>(), name);
        CHECK(isMember(n, false) == r["member"].get<bool>(), name);

//! `UaKinds`: QML singleton over `scaas-ua`. Bytes travel as "0x…" hex strings. Every invokable clears `lastError`, and on
//! failure sets it to the error code and returns "" (strings) or false (bools); panics never cross the FFI.
#[cxx_qt::bridge]
pub mod qobject {
    unsafe extern "C++" {
        include!("cxx-qt-lib/qstring.h");
        type QString = cxx_qt_lib::QString;
    }

    extern "RustQt" {
        #[qobject]
        #[qml_element]
        #[qml_singleton]
        #[qproperty(QString, last_error, cxx_name = "lastError")]
        type UaKinds = super::UaKindsRust;

        #[qinvokable] #[cxx_name = "kindInfo"] fn kind_info(self: Pin<&mut Self>, kind: i32) -> QString;
        #[qinvokable] fn tag(self: Pin<&mut Self>, kind: i32) -> QString;
        #[qinvokable] #[cxx_name = "kindTagString"] fn kind_tag_string(self: Pin<&mut Self>, kind: i32) -> QString;
        #[qinvokable] #[cxx_name = "groupTag"] fn group_tag(self: Pin<&mut Self>, group: &QString) -> QString;
        #[qinvokable] #[cxx_name = "groupTagString"] fn group_tag_string(self: Pin<&mut Self>, group: &QString) -> QString;
        #[qinvokable] #[cxx_name = "msgTag"] fn msg_tag(self: Pin<&mut Self>) -> QString;
        #[qinvokable] #[cxx_name = "purposeTag"] fn purpose_tag(self: Pin<&mut Self>, purpose: &QString) -> QString;
        #[qinvokable] #[cxx_name = "uaOf"] fn ua_of(self: Pin<&mut Self>, kind: i32, key_data: &QString) -> QString;
        #[qinvokable] #[cxx_name = "deriveUA"]
        fn derive_ua(self: Pin<&mut Self>, kind: i32, key_data: &QString, hedera_native: bool) -> QString;

use core::pin::Pin;
use cxx_qt_lib::QString;
use scaas_ua as ua;
use std::panic::{catch_unwind, AssertUnwindSafe};

#[derive(Default)]
pub struct UaKindsRust {
    last_error: QString,
}

/// Error code: a `scaas-ua` code; `UAKeyData` for undecodable key data; `UAArgument` for other input the binding cannot
/// decode (bad hex / length / range of digests, ids, purposes, chain ids, JSON).
type Res<T> = Result<T, &'static str>;
const ARG: &str = "UAArgument";

fn from_ua<T>(r: ua::Result<T>) -> Res<T> {
    r.map_err(|e| e.code())
}
fn s(q: &QString) -> String {
    String::from(q)
}
fn hx(b: &[u8]) -> String {
    let mut o = String::with_capacity(2 + 2 * b.len());
    o.push_str("0x");
    for x in b {
        o.push_str(&format!("{x:02x}"));
    }
    o
}
fn bytes(q: &QString) -> Res<Vec<u8>> {
    let t = s(q);
    let h = t.strip_prefix("0x").unwrap_or(&t);
    if h.len() % 2 != 0 || !h.bytes().all(|c| c.is_ascii_hexdigit()) {
        return Err(ARG);
    }
    Ok((0..h.len()).step_by(2).map(|i| u8::from_str_radix(&h[i..i + 2], 16).unwrap()).collect())
}
/// Key data and native ids: undecodable hex is malformed key data (`UAKeyData`), as in every other UA library.
fn key(q: &QString) -> Res<Vec<u8>> {
    bytes(q).map_err(|_| "UAKeyData")
}
fn fixed<const N: usize>(q: &QString) -> Res<[u8; N]> {
    bytes(q)?.try_into().map_err(|_| ARG)
}
fn k(kind: i32) -> Res<u16> {
    u16::try_from(kind).map_err(|_| ARG)
}
fn id(v: f64) -> Res<u64> {
    if v.fract() == 0.0 && (0.0..=9007199254740992.0).contains(&v) { Ok(v as u64) } else { Err(ARG) }
}
fn domain(generation: i32, chain_id: f64, registry: &QString, chain_uid: &QString) -> Res<ua::Domain> {
    Ok(ua::Domain {
        generation: u32::try_from(generation).map_err(|_| ARG)?,
        chain_id: id(chain_id)?,
        registry: fixed(registry)?,
        chain_uid: fixed(chain_uid)?,
    })
}

impl qobject::UaKinds {
    /// Clear `lastError`, run `f` (panic-guarded); on failure set `lastError` and return `T::default()`.
    fn run<T: Default>(mut self: Pin<&mut Self>, f: impl FnOnce() -> Res<T>) -> T {
        self.as_mut().set_last_error(QString::default());
        match catch_unwind(AssertUnwindSafe(f)).unwrap_or(Err("UAInternal")) {
            Ok(v) => v,
            Err(code) => {
                self.set_last_error(QString::from(code));
                T::default()
            }
        }
    }
    fn hex(self: Pin<&mut Self>, f: impl FnOnce() -> Res<Vec<u8>>) -> QString {
        QString::from(&self.run(|| f().map(|b| hx(&b))))
    }

    pub fn kind_info(self: Pin<&mut Self>, kind: i32) -> QString {
        QString::from(&self.run(|| {
            let i = from_ua(ua::kind_info(k(kind)?))?;
            Ok(serde_json::json!({"kind": i.kind, "name": i.name, "native": i.native, "lengths": i.lengths, "group": i.group})
                .to_string())
        }))
    }
    pub fn tag(self: Pin<&mut Self>, kind: i32) -> QString {
        self.hex(|| Ok(from_ua(ua::tag(k(kind)?))?.to_vec()))
    }
    pub fn kind_tag_string(self: Pin<&mut Self>, kind: i32) -> QString {
        QString::from(&self.run(|| from_ua(ua::kind_tag_string(k(kind)?))))
    }
    pub fn group_tag(self: Pin<&mut Self>, group: &QString) -> QString {
        self.hex(|| Ok(ua::group_tag(&s(group)).ok_or("UAKindUnknown")?.to_vec()))
    }
    pub fn group_tag_string(self: Pin<&mut Self>, group: &QString) -> QString {
        QString::from(&self.run(|| ua::group_tag_string(&s(group)).ok_or("UAKindUnknown")))
    }
    pub fn msg_tag(self: Pin<&mut Self>) -> QString {
        self.hex(|| Ok(ua::msg_tag().to_vec()))
    }
    pub fn purpose_tag(self: Pin<&mut Self>, purpose: &QString) -> QString {
        self.hex(|| Ok(from_ua(ua::purpose_tag(&s(purpose)))?.to_vec()))
    }
    pub fn ua_of(self: Pin<&mut Self>, kind: i32, key_data: &QString) -> QString {
        self.hex(|| Ok(from_ua(ua::ua_of(k(kind)?, &key(key_data)?))?.to_vec()))
    }
    pub fn derive_ua(self: Pin<&mut Self>, kind: i32, key_data: &QString, hedera_native: bool) -> QString {
        self.hex(|| Ok(from_ua(ua::derive_ua(k(kind)?, &key(key_data)?, hedera_native))?.to_vec()))
    }
    pub fn native_id(self: Pin<&mut Self>, kind: i32, raw: &QString) -> QString {
        self.hex(|| Ok(from_ua(ua::native_id(k(kind)?, &key(raw)?))?.to_vec()))
    }
    pub fn key_hash_of(self: Pin<&mut Self>, kind: i32, key_data: &QString) -> QString {
        QString::from(&self.run(|| Ok(from_ua(ua::key_hash_of(k(kind)?, &key(key_data)?))?.map(|h| hx(&h)).unwrap_or_default())))
    }
    pub fn validate_key_data(self: Pin<&mut Self>, kind: i32, key_data: &QString, hedera_native: bool) -> bool {
        self.run(|| from_ua(ua::validate_key_data(k(kind)?, &key(key_data)?, hedera_native)).map(|_| true))
    }
    pub fn in_native_space(self: Pin<&mut Self>, id: &QString) -> bool {
        self.run(|| Ok(ua::in_native_space(&fixed(id)?)))
    }
    pub fn is_native(self: Pin<&mut Self>, kind: i32) -> bool {
        self.run(|| Ok(ua::is_native(k(kind)?)))
    }
    pub fn is_zether(self: Pin<&mut Self>, kind: i32) -> bool {
        self.run(|| Ok(ua::is_zether(k(kind)?)))
    }
    pub fn is_signing(self: Pin<&mut Self>, kind: i32) -> bool {
        self.run(|| Ok(ua::is_signing(k(kind)?)))
    }
    pub fn is_member(self: Pin<&mut Self>, kind: i32, hedera_native: bool) -> bool {
        self.run(|| Ok(ua::is_member(k(kind)?, hedera_native)))
    }
    pub fn ua_message(self: Pin<&mut Self>, kind: i32, purpose: &QString, digest: &QString) -> QString {
        self.hex(|| Ok(from_ua(ua::ua_message(k(kind)?, &fixed(purpose)?, &fixed(digest)?))?.to_vec()))
    }
    pub fn chain_key_hash(self: Pin<&mut Self>, chain_id: f64) -> QString {
        self.hex(|| Ok(ua::chain_key_hash(id(chain_id)?).to_vec()))
    }
    pub fn pop_digest(self: Pin<&mut Self>, chain_id: f64, chain_uid: &QString, registry: &QString, ua: &QString, auth_ref: &QString) -> QString {
        self.hex(|| Ok(ua::pop_digest(id(chain_id)?, &fixed(chain_uid)?, &fixed(registry)?, &fixed(ua)?, &fixed(auth_ref)?).to_vec()))
    }
    pub fn ua_auth_domain_separator(self: Pin<&mut Self>, generation: i32, chain_id: f64, registry: &QString, chain_uid: &QString) -> QString {
        self.hex(|| Ok(ua::ua_auth_domain_separator(&domain(generation, chain_id, registry, chain_uid)?).to_vec()))
    }
    pub fn ua_auth_digest(self: Pin<&mut Self>, generation: i32, chain_id: f64, registry: &QString, chain_uid: &QString, ua: &QString, purpose: &QString, digest: &QString) -> QString {
        self.hex(|| {
            let d = domain(generation, chain_id, registry, chain_uid)?;
            Ok(ua::ua_auth_digest(&d, &fixed(ua)?, &fixed(purpose)?, &fixed(digest)?).to_vec())
        })
    }
    pub fn member_digest(self: Pin<&mut Self>, structure_ua: &QString, ua_msg: &QString) -> QString {
        self.hex(|| Ok(ua::member_digest(&fixed(structure_ua)?, &fixed(ua_msg)?).to_vec()))
    }
    pub fn canonical_id(self: Pin<&mut Self>, text: &QString) -> QString {
        QString::from(&self.run(|| from_ua(ua::canonical_id(&s(text)))))
    }
    pub fn encode_msig(self: Pin<&mut Self>, threshold: i32, members: &QString) -> QString {
        self.hex(|| {
            let v: Vec<(i32, String, i32)> = serde_json::from_str(&s(members)).map_err(|_| ARG)?;
            let m = v
                .iter()
                .map(|(kd, idh, w)| Ok((k(*kd)?, fixed::<32>(&QString::from(idh))?, u16::try_from(*w).map_err(|_| ARG)?)))
                .collect::<Res<Vec<_>>>()?;
            Ok(ua::encode_msig(u16::try_from(threshold).map_err(|_| ARG)?, &m))
        })
    }
}

//! flutter_rust_bridge surface over `scaas-ua`. Every function is synchronous; failures are a `UAError { code, reason }`
//! (a Dart exception). Byte data is `Uint8List` (`Vec<u8>`), ids and digests are fixed-size arrays.
use flutter_rust_bridge::frb;

/// `code` is one of the seven shared codes (`UAKeyData`, `UAKindUnknown`, ...); `reason` is `Display` text.
#[derive(Debug, Clone)]
pub struct UAError {
    pub code: String,
    pub reason: String,
}

impl From<scaas_ua::UAError> for UAError {
    fn from(e: scaas_ua::UAError) -> Self {
        UAError { code: e.code().into(), reason: e.to_string() }
    }
}

type R<T> = Result<T, UAError>;

pub struct KindInfo {
    pub kind: u16,
    pub name: String,
    pub native: bool,
    /// Empty = variable length.
    pub lengths: Vec<u32>,
    pub group: Option<String>,
}

/// The registry's EIP-712 domain.
pub struct UaDomain {
    pub generation: u32,
    pub chain_id: u64,
    pub registry: [u8; 20],
    pub chain_uid: [u8; 32],
}

impl From<UaDomain> for scaas_ua::Domain {
    fn from(d: UaDomain) -> Self {
        scaas_ua::Domain { generation: d.generation, chain_id: d.chain_id, registry: d.registry, chain_uid: d.chain_uid }
    }
}

Uint8List bytes(String s) {
  final h = s.substring(2);
  return Uint8List.fromList([for (var i = 0; i < h.length; i += 2) int.parse(h.substring(i, i + 2), radix: 16)]);

U8Array20 b20(String s) => U8Array20(bytes(s));

/// Runs [f]; returns the UAError code it throws, or null if it does not throw.
String? errCode(void Function() f) {
  try {
    f();
  } on UAError catch (e) {
    return e.code;
  }
  return null;
}

import 'dart:typed_data';

// Keccak-256 (original 0x01 padding, not SHA3's 0x06). Lanes are kept as two 32-bit halves so the code is exact when
// compiled to JS, where `int` is a double and bit operations are 32-bit.
const int _m = 0xFFFFFFFF;

final List<int> _rcLo = List.filled(24, 0), _rcHi = List.filled(24, 0);
final List<int> _rho = List.filled(25, 0);

bool _init = _setup();
bool _setup() {
  int bit(int t) {
    var r = 1;
    for (var i = 0; i < t % 255; i++) {
      r <<= 1;
      if (r & 0x100 != 0) r ^= 0x171;
    }
    return r & 1;
  }

  for (var ir = 0; ir < 24; ir++) {
    for (var j = 0; j < 7; j++) {
      if (bit(j + 7 * ir) == 1) {
        final pos = (1 << j) - 1; // bit position in the 64-bit lane
        if (pos < 32) {
          _rcLo[ir] |= 1 << pos;
        } else {
          _rcHi[ir] |= 1 << (pos - 32);
        }
      }
    }
  }
  var x = 1, y = 0;
  for (var t = 0; t < 24; t++) {
    _rho[x + 5 * y] = ((t + 1) * (t + 2) ~/ 2) % 64;
    final nx = y;
    y = (2 * x + 3 * y) % 5;
    x = nx;
  }
  return true;
}

void _f(Uint32List s) {
  final c = Uint32List(10), b = Uint32List(50);
  for (var round = 0; round < 24; round++) {
    for (var x = 0; x < 5; x++) {
      var lo = 0, hi = 0;
      for (var y = 0; y < 25; y += 5) {
        lo ^= s[2 * (x + y)];
        hi ^= s[2 * (x + y) + 1];
      }
      c[2 * x] = lo;
      c[2 * x + 1] = hi;
    }
    for (var x = 0; x < 5; x++) {
      final p = (x + 4) % 5, n = (x + 1) % 5;
      final nl = c[2 * n], nh = c[2 * n + 1];
      // rotl64(C[n], 1)
      final rl = ((nl << 1) | (nh >>> 31)) & _m, rh = ((nh << 1) | (nl >>> 31)) & _m;
      final dl = (c[2 * p] ^ rl) & _m, dh = (c[2 * p + 1] ^ rh) & _m;
      for (var y = 0; y < 25; y += 5) {
        s[2 * (x + y)] ^= dl;
        s[2 * (x + y) + 1] ^= dh;
      }
    }
    // rho + pi: B[y, 2x+3y] = rotl(A[x, y], rho)
    for (var x = 0; x < 5; x++) {
      for (var y = 0; y < 5; y++) {
        var lo = s[2 * (x + 5 * y)], hi = s[2 * (x + 5 * y) + 1];
        var n = _rho[x + 5 * y];
        if (n >= 32) {
          final t = lo;
          lo = hi;
          hi = t;
          n -= 32;
        }
        if (n > 0) {
          final nl = ((lo << n) | (hi >>> (32 - n))) & _m, nh = ((hi << n) | (lo >>> (32 - n))) & _m;
          lo = nl;
          hi = nh;
        }
        final d = y + 5 * ((2 * x + 3 * y) % 5);
        b[2 * d] = lo;
        b[2 * d + 1] = hi;
      }
    }
    // chi
    for (var y = 0; y < 25; y += 5) {
      for (var x = 0; x < 5; x++) {
        final a = 2 * (y + x), n1 = 2 * (y + (x + 1) % 5), n2 = 2 * (y + (x + 2) % 5);
        s[a] = (b[a] ^ ((~b[n1] & _m) & b[n2])) & _m;
        s[a + 1] = (b[a + 1] ^ ((~b[n1 + 1] & _m) & b[n2 + 1])) & _m;
      }
    }
    s[0] ^= _rcLo[round];
    s[1] ^= _rcHi[round];
  }
}

/// keccak-256 of the concatenation of [parts].
Uint8List keccak256(List<Uint8List> parts) {
  assert(_init);
  const rate = 136;
  var len = 0;
  for (final p in parts) {
    len += p.length;
  }
  final padded = Uint8List(((len ~/ rate) + 1) * rate);
  var o = 0;
  for (final p in parts) {
    padded.setRange(o, o + p.length, p);
    o += p.length;
  }
  padded[len] ^= 0x01;
  padded[padded.length - 1] ^= 0x80;
  final s = Uint32List(50);
  for (var off = 0; off < padded.length; off += rate) {
    for (var i = 0; i < rate ~/ 4; i++) {
      final k = off + 4 * i;
      s[i] ^= padded[k] | padded[k + 1] << 8 | padded[k + 2] << 16 | padded[k + 3] << 24;
    }
    _f(s);
  }
  final out = Uint8List(32);
  for (var i = 0; i < 32; i++) {
    out[i] = (s[i ~/ 4] >>> (8 * (i % 4))) & 0xFF;
  }
  return out;
}

_F2 _add(_F2 a, _F2 b, BigInt p) => _F2((a.a0 + b.a0) % p, (a.a1 + b.a1) % p);
_F2 _sub(_F2 a, _F2 b, BigInt p) => _F2((a.a0 - b.a0) % p, (a.a1 - b.a1) % p);

  _F2 l;

    if (a.y != c.y || a.y.isZero) return null; // P + (-P), or doubling a 2-torsion point

void _ed25519(Uint8List b) {
  var v = BigInt.zero;
  for (var i = 31; i >= 0; i--) {
    v = (v << 8) | BigInt.from(b[i]);

  final sign = (v >> 255).toInt();
  final y = v & ((BigInt.one << 255) - BigInt.one);
  _need(y < _edP, 'range');
  final x2 = ((y * y - BigInt.one) * _inv(_edD * y * y + BigInt.one, _edP)) % _edP;
  var x = x2.modPow((_edP + BigInt.from(3)) ~/ BigInt.from(8), _edP);
  if ((x * x - x2) % _edP != BigInt.zero) x = (x * _edSqrtM1) % _edP;
  _need((x * x - x2) % _edP == BigInt.zero, 'curve');
  _need(!(x == BigInt.zero && sign == 1), 'sign');

  if (!groups.contains(group)) throw ArgumentError('unknown keyHash group $group');
  return 'scaas.ua.group.$group.v1';
}

}

Uint8List _sized(Uint8List b, int n, String what) {
  if (b.length != n) throw ArgumentError('$what must be $n bytes');
  return b;
}

String _hex(Uint8List b) => b.map((x) => x.toRadixString(16).padLeft(2, '0')).join();

/// keccak256(TAG(kind) ‖ keyData); no validation (see [deriveUA]). [keyData]: Uint8List or hex String.
Uint8List uaOf(int kind, Object? keyData) => _k([tag(kind), keyBytes(keyData)]);

bool inNativeSpace(Uint8List id) {
  _sized(id, 32, 'id');
  for (var i = 0; i < 12; i++) {
    if (id[i] != 0) return false;
  }
  return true;
}

/// Validate, derive, refuse an id whose top 96 bits are zero (CTR-UA-03).
Uint8List deriveUA(int kind, Object? keyData, {bool hederaNative = false}) {
  validateKeyData(kind, keyData, hederaNative: hederaNative);
  final ua = uaOf(kind, keyData);
  if (inNativeSpace(ua)) throw UAError('UAIdInNativeSpace', _hex(ua));
  return ua;
}

/// A native id left-padded to 32 bytes. [raw]: Uint8List or hex String.
Uint8List nativeId(int kind, Object? raw) {
  final k = kindInfo(kind);
  if (!k.native) throw UAError('UAKindNotNative', k.name);
  final r = keyBytes(raw);
  if (!k.lengths.contains(r.length)) throw UAError('UAKeyData', 'length');
  final id = Uint8List(32);
  id.setRange(32 - r.length, 32, r);
  return id;
}

/// keccak256(GROUP(g) ‖ canonical pubkey), null for structures. Call on validated key data.
Uint8List? keyHashOf(int kind, Object? keyData) {
  final k = _derived(kind);
  final g = k.group;
  if (g == null) return null;
  final d = keyBytes(keyData);
  final (lo, hi) = switch (kind) {
    0x0100 || 0x0101 => (0, 32),
    0x0110 || 0x0111 => (1, 33),
    0x0112 || 0x0113 => (0, 64),
    _ => (0, d.length),
  };
  if (d.length < hi) throw UAError('UAKeyData', 'length');
  return _k([groupTag(g), Uint8List.sublistView(d, lo, hi)]);
}

Uint8List uaMessage(int kind, Uint8List purpose, Uint8List digest) =>
    _k([msgTag, tag(kind), _sized(purpose, 32, 'purposeTag'), _sized(digest, 32, 'digest')]);

BigInt _id(int v) {
  if (v < 0) throw ArgumentError('chainId must be non-negative');
  return BigInt.from(v);
}

/// [chainId] is a Dart int: exact up to 2^63-1 on the VM, up to 2^53 when compiled to JS.
Uint8List chainKeyHash(int chainId) => _k([_utf8('evm:${_id(chainId)}')]);

Uint8List _word(int v) {
  var x = _id(v);
  final w = Uint8List(32);
  for (var i = 31; i >= 24; i--) {
    w[i] = (x & BigInt.from(0xff)).toInt();
    x >>= 8;
  }
  return w;
}

Uint8List _addressWord(Uint8List a) {
  final w = Uint8List(32);
  w.setRange(12, 32, _sized(a, 20, 'registry'));
  return w;
}

/// pop_digest (CTR-UA-07).
Uint8List popDigest(int chainId, Uint8List chainUid, Uint8List registry, Uint8List ua, Uint8List authRef) => _k([
      purposeTag('pop'),
      chainKeyHash(chainId),
      _sized(chainUid, 32, 'chainUid'),
      _addressWord(registry),
      _sized(ua, 32, 'ua'),
      _sized(authRef, 32, 'authRef'),
    ]);

/// The registry's EIP-712 domain ("SCaaS UARegistry", "<generation>", chainId, registry, salt = chainUid).
class Domain {
  final int generation, chainId;
  final Uint8List registry, chainUid;
  Domain(this.generation, this.chainId, this.registry, this.chainUid);
}

Uint8List uaAuthDomainSeparator(Domain d) => _k([
      _k([_utf8(domainType)]),
      _k([_utf8(registryName)]),
      _k([_utf8('${_id(d.generation)}')]),
      _word(d.chainId),
      _addressWord(d.registry),
      _sized(d.chainUid, 32, 'chainUid'),
    ]);

/// EIP-712 digest of UAAuth(ua, purpose, digest): what native signers behind the registry sign.
Uint8List uaAuthDigest(Domain d, Uint8List ua, Uint8List purpose, Uint8List digest) => _k([
      Uint8List.fromList([0x19, 0x01]),
      uaAuthDomainSeparator(d),
      _k([_k([_utf8(uaAuthType)]), _sized(ua, 32, 'ua'), _sized(purpose, 32, 'purposeTag'), _sized(digest, 32, 'digest')]),
    ]);

Uint8List memberDigest(Uint8List structureUa, Uint8List uaMsg) =>
    _k([_sized(structureUa, 32, 'structureUa'), _sized(uaMsg, 32, 'uaMsg')]);

final _idPattern = RegExp(r'^0x([0-9a-fA-F]{40}|[0-9a-fA-F]{64})$');

/// Lower-case hex; a 32-byte id with the top 96 bits zero is written as its 20-byte native id (CTR-UA-03).
String canonicalId(String text) {
  // `$` in Dart matches only at the end (not before a trailing \n) unless multiLine is set.
  final m = _idPattern.firstMatch(text);
  if (m == null) throw UAError('UAIdFormat', text);
  final h = m.group(1)!.toLowerCase();
  return '0x${h.length == 64 && h.startsWith('0' * 24) ? h.substring(24) : h}';
}

/// u16 threshold ‖ u16 count ‖ count × (u16 kind ‖ bytes32 id ‖ u16 weight). Members: (kind, id, weight).
Uint8List encodeMsig(int threshold, List<(int, Uint8List, int)> members) {
  void u16(List<int> o, int v) {
    if (v < 0 || v > 0xffff) throw ArgumentError('u16 out of range');
    o..add(v >> 8)..add(v & 0xff);
  }

  final o = <int>[];
  u16(o, threshold);
  u16(o, members.length);
  for (final (kind, id, weight) in members) {
    u16(o, kind);
    o.addAll(_sized(id, 32, 'member id'));
    u16(o, weight);
  }
  return Uint8List.fromList(o);
}
