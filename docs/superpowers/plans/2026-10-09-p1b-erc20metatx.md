# P1b — `ERC20MetaTx` on `MetaTxBase`: `MetaTransfer`, fee classes, allowance rule, receiver-pays — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the built v2 token line (`MetaTokenBase` and the three tiers, plus their Hedera children) off the
legacy `MetaTxCore` pipeline onto the P1a base: a new abstract `ERC20MetaTx is ERC20, MetaTxBase` with the typed
`MetaTransfer` path (`mtxExecuteTransfer`, `mtxBatchTransfer`), the fee in this token by selector fee class, the
allowance rule (caller **and** spender contracts), "no tokens at the token's address"; per-kind selector allowlists
(gasless `burn`/`wrap`/`unwrap`/`addReserve` through `mtxExecute`); the named functions rebuilt on the two v3 structs;
receiver-pays; conformance tests, a `msg.sender` lint and the two KATs on a real token.

**Architecture:** `MetaTxBase` (P1a, unchanged except a removed `virtual`) → `ERC20MetaTx` (new file; the legacy
`MetaTxCore` is deleted, its text survives in `legacy/` and under the tag `ref/pre-token-tree`) → `MetaTokenBase`
(rewritten in place: named builders, receiver-pays, no op dispatch) → `NormalToken` / `SingleUnderlyingToken` /
`MultiUnderlyingToken` (+ Hedera children) with their allowlists. The v1 line (`ERC20MetaTx` v1 mixin, `MetaToken`,
`HederaMetaToken`, `MetaTxDex`, v1 `OpenFactory`) and Zether stay as built under `…V1` interface names until P1e/P3.
Domain becomes `("SCaaS MetaToken", "1", chainId, clone, chain_uid)`; implementations take `chainUid_` in the
constructor.

**Tech Stack:** Solidity 0.8.28, Foundry (forge 1.3.5), OpenZeppelin Contracts 5.2.0, forge-std 1.16.2; `cast` for
the KAT cross-check; Python only in the other repo (bamboo-dms, Task 9).

**Spec:** `docs/history/specs/2026-10-08-token-tree-design.md` (§3 tree, §4 hot paths/size, §8 deleted, §9 P1);
normative rules in `docs/contracts/metatx.md` (CTR-MTX-01, -05, -06, -07, -08, -09, -10, -11, -12, -13, -15, -17,
-18, -19, -20, -21, -23, -24, Interfaces, Conformance, Transitional (BUILT)), `docs/contracts/token-wrappers.md`
(CTR-TOK-01 allowance lockdown, CTR-TOK-24 size budget, §8 storage layout), `docs/contracts/accounts.md`
(CTR-ACC-11 SmartKeyAccount name); register entries in `docs/decisions.md`; TODO.md §00 "P1b notes" (a)–(h);

## Rulings (docs vs code) and defaults taken

- **R1 — Free the target names by suffixing the v1 line.** The target `ERC20MetaTx`, `IERC20MetaTx` and
  `IERC20Payment` names are taken by the v1 line, which P1e deletes. Task 1 renames the v1 files and identifiers to
  `ERC20MetaTxV1`, `IERC20MetaTxV1`, `IERC20PaymentV1` (pure rename, all green); the target interfaces are new files
  (Task 2). Comments that name the *target* `ERC20MetaTx` (MetaTxBase, SCaaSDex, UniversalAccountRegistry,
  HederaAccountAuth) are not touched.
- **R2 — `ERC20MetaTx` is a new file; `MetaTxCore` is `git rm`'d in Task 4.** The rewrite shares almost no text with
  `MetaTxCore`, so `git mv` would not keep useful history; the old text stays in `legacy/src/metatx/MetaTxCore.sol`
  and under `ref/pre-token-tree`. `ERC20MetaTx` lands first on a harness (Task 3), then the v2 line moves onto it
  (Task 4).
- **R3 — Size: the wrapper tiers are over EIP-170 until P1d (transitional, flag to the owner).** With the full base,
  `Single`/`Multi` and their Hedera children measure 26.0–28.2 KB (table above). The cure is the token-tree design
  itself: P1c moves pay/admin into `PayLib`/`AdminLib`, P1d replaces Single+Multi with `WrappedToken` +
  `WrappedLib` (wrap/unwrap/rates in a library). Pulling those libraries into P1b would merge three plans. Forge
  tests do not enforce EIP-170 (`ZetherToken` at 28.8 KB already deploys in tests), but **the wrapper
  implementations cannot be deployed on a real chain between P1b and P1d** (nothing is deployed today). Gate of this
  plan: `NormalToken` and `HederaNoUnderlyingToken` ≤ 20,480 B; no contract other than `ZetherToken` and the four
  wrapper implementations over 24,576 B; the wrappers under the ceilings pinned in `FactoryV2.t.sol`
  (`26,624` Single, `27,648` Multi) so they cannot grow unnoticed.
- **R4 — UA path deferred.** TODO MT-2 lists "UA path split into `UAMetaTransaction`/`UAMetaTransfer` +
  `uaExecuteTransfer`/`uaBatchTransfer` (CTR-UA-26)". No UA ledger is built (no `_uaBalance`, no `ua*` function, no
  registry auth in any token); "splitting" it means building it, which is the UA F-stream (registry-backed auth,
  `bytes32` nonce map) and would also add bytes to every token. P1b builds nothing of it; TODO keeps the item under UA
  F1 with the two structs as its starting point. Flag to the owner.
- **R5 — Receiver-pays lives in `MetaTokenBase`** (CTR-MTX-05 "in `MetaTokenBase`", beside `mtxPay` and `payLane`,
  which it uses). The tree text of CTR-MTX-07 says `ERC20MetaTx` holds receiver-pays; Task 8 aligns that sentence.
- **R6 — `FeeRecipientIsPayee` is declared in `IERC20MetaTx`** (the typed pipeline of `ERC20MetaTx` raises it);
  metatx.md Interfaces lists it under `MetaTokenBase` — Task 8 moves it.
- **R7 — SmartKeyAccount name on the token side now** (owner, 2026-10-09 in session): the constructor parameter and
  immutables become `smartKeyAccountImpl_`, `SMART_KEY_ACCOUNT_IMPL`, `_SMART_KEY_CLONE_CODEHASH` (were
  `SUBJECT_ACCOUNT_IMPL`…). The account contract itself stays `SubjectAccount` until P4 (CTR-ACC-11); v1 `MetaToken`
  keeps its names (deleted in P1e).
- **R8 — Domain, constructor, deploy scripts.** Implementations take `bytes32 chainUid_` (last constructor
  argument); `SaltedEIP712` refuses 0. `script/Deploy.s.sol` and `script/hedera/DeployHedera.s.sol` read it from env
  `CHAIN_UID` (from `smartcontracts/evm/chain-uids.json`); the `chainUid()` deploy gate is P1e.
- **R9 — Storage layout shifts** (OZ `EIP712` fallback strings and `_metaNonce` leave the linear layout; nonces live
  in ERC-7201 `scaas.metatx`): `creator…_legCount` slot 5, `_tokenName` 6, `_tokenSymbol` 7, `minter` 8; Single
  `_legs` 8, `_legIndex` 9, `_pending` 10, rate config 11; Multi `guardian` 12. Layout pins are regenerated; P1c
  moves the state into `scaas.token`.
- **R10 — Removed with the legacy pipeline:** ops `pay`/`trade`/`approve`/`unwrap` in `data`, `MetaTxUnknownOp`,
  `TradeLegNotRestricted`, `ApproveCarriesValue`, `ApproveSpenderMismatch`, `UnwrapRecipientMismatch`, `mtxUnwrap`,
  `mtxUnwrapWithFee` + `fallback` + `IMetaTokenV2UnwrapWithFee` (gasless unwrap = `mtxExecute(unwrap…)`, CTR-MTX-12),
  `executeMetaTransactionWithFee` (→ `mtxExecuteWithFee(MetaTransaction)`), the legacy `mtxBatch` (→ `MetaTxBase.mtxBatch`
  for calls, `mtxBatchTransfer` for transfers), `metaNonce`/`metaTxDigest`/`cancelMetaNonce` (→ `mtxNonce`,
  `mtxDigest`/`mtxTransferDigest`, `cancelNonce`), `metatx_v2_kat.json` and its writer `BaseKat.t.sol`. Trade
  returns in P2 (`TradeLib`). A transfer to `address(0)` now fails `PayToZero()` at step 3 (was `ERC20InvalidReceiver`).
- **Defaults (docs silent):** `_chargeFee` re-derives the fee class with `_mtxRule(bytes4(m.data))` (no change to the
  P1a hook signature); `ABSOLUTE` + `FIXED` charges `m.fee` uncapped, `AMOUNT` uses `FeePolicy.compute` (cap 1 %);
  the resolved fee recipient is `m.feeRecipient` or `msg.sender`; `mtxWrap` (MT-3's second half, CTR-TOK-20) is
  P1d with `WrappedLib` (HANDOFF phase table), not P1b; a fee or a transfer **to the token itself** is
  refused (`TransferToSelf`, checked in `_update` and at step 3 of the typed path); `payWithFee` stays unguarded as
  built; the receiver-fee shape checks the fee nibble with `mode & MODE_FEE_MASK != 0` (so an invalid nibble is a
  shape error, not `ModeFeeInvalid`). Optional P1b note (g) (fee check before the call; a dedicated error for an
  unguarded allowlisted target) is **not** done: nothing requires it.

```solidity
    struct MetaTransfer {
        address from;           // signer and payer
        address to;             // payee
        uint256 value;          // amount moved
        bytes32 entryRef;       // 0 = transfer; != 0 = payment reference (PaymentSettled)
        uint256 batch;          // lane, shared with MetaTransaction (one nonce space)
        uint256 nonce;
        uint256 validUntil;
        uint32  mode;

        uint256 fee;

    bytes32 internal constant METATRANSFER_TYPEHASH = keccak256(
        "MetaTransfer(address from,address to,uint256 value,bytes32 entryRef,uint256 batch,uint256 nonce,uint256 validUntil,uint32 mode,address relayer,uint256 fee,address feeRecipient)"
    );

    function canon(MetaTransfer memory t) internal pure returns (address r, address f) {
        r = (t.mode & MODE_RESTRICT_RELAYER)       != 0 ? t.relayer      : address(0);
        f = (t.mode & MODE_RESTRICT_FEE_RECIPIENT) != 0 ? t.feeRecipient : address(0);

    function hashStruct(MetaTransfer memory t) internal pure returns (bytes32) {
        (address r, address f) = canon(t);
        return keccak256(abi.encode(
            METATRANSFER_TYPEHASH, t.from, t.to, t.value, t.entryRef, t.batch, t.nonce, t.validUntil, t.mode, r, t.fee, f

    }
```

```solidity
// SPDX-License-Identifier: Apache-2.0
pragma solidity ^0.8.24;

import {ERC20} from "@openzeppelin/contracts/token/ERC20/ERC20.sol";
import {IERC20} from "@openzeppelin/contracts/token/ERC20/IERC20.sol";
import {Context} from "@openzeppelin/contracts/utils/Context.sol";
import {MetaTxBase} from "./MetaTxBase.sol";
import {IMetaTx} from "./IMetaTx.sol";
import {IERC20Payment} from "./IERC20Payment.sol";
import {MetaTxLib} from "../common/MetaTxLib.sol";
import {FeePolicy, FeeMode} from "../common/FeePolicy.sol";
import {SigCheck} from "../common/SigCheck.sol";

/// @title The token base of every SCaaS token (CTR-MTX-07): ERC-20 on `MetaTxBase`.
/// @notice Adds to the generic base: the fee in this token (`_chargeFee` by fee class, CTR-MTX-20), the typed
///         `MetaTransfer` path (`mtxExecuteTransfer`, `mtxBatchTransfer`, CTR-MTX-23/24) on the same lanes, the
///         allowance rule (CTR-TOK-01) and "no tokens at the token's own address" (CTR-MTX-18). Domain
///         `("SCaaS MetaToken", "1", chainId, clone, chain_uid)` for every kind (CTR-MTX-02).
abstract contract ERC20MetaTx is ERC20, MetaTxBase, IERC20Payment {
    using MetaTxLib for MetaTxLib.MetaTransfer;

    constructor(bytes32 chainUid_) ERC20("", "") MetaTxBase("SCaaS MetaToken", chainUid_) {}

    // ------------------------------------------------------------------ views

    /// @notice `0xF3`: both flags and every fee mode (a token holds the charged balance).
    function supportedModes() public pure override(IMetaTx, MetaTxBase) returns (uint32) {
        return MetaTxLib.MODE_KNOWN_MASK;
    }

    function mtxTransferDigest(MetaTxLib.MetaTransfer calldata t) external view returns (bytes32) {
        return _hashTypedDataV4(t.hashStruct());
    }

    // ------------------------------------------------------------------ typed path (CTR-MTX-23, CTR-MTX-24)

    function mtxExecuteTransfer(MetaTxLib.MetaTransfer calldata t, bytes calldata signature)
        external nonReentrant returns (bool)
    {
        _executeTransfer(t, signature);
        return true;
    }

    /// @notice Atomic, items in order; never mixed with `MetaTransaction`s (CTR-MTX-24).
    function mtxBatchTransfer(MetaTxLib.MetaTransfer[] calldata ts, bytes[] calldata signatures)
        external nonReentrant returns (bool)
    {
        uint256 n = ts.length;
        if (n == 0) revert MtxBatchEmpty();
        if (n != signatures.length) revert MtxBatchLengthMismatch();
        for (uint256 i; i < n; ++i) _executeTransfer(ts[i], signatures[i]);
        return true;
    }

    /// @dev Every typed entry (struct, batch, the named builders, receiver-pays) goes through here. Everything is
    ///      checked before the nonce and the transfers, which cannot fail afterwards. Returns the digest.
    function _executeTransfer(MetaTxLib.MetaTransfer memory t, bytes calldata signature)
        internal returns (bytes32 digest)
    {
        _checkEnvelope(t.from, t.batch, t.nonce, t.validUntil, t.mode, t.relayer);              // 1
        digest = _hashTypedDataV4(t.hashStruct());                                              // 2
        _requireValidSignature(t.from, digest, signature);
        (uint256 fee, address feeTo) = _checkTransfer(t);                                       // 3
        _useNonce(t.from, t.batch);                                                             // 4
        if (fee != 0) _transfer(t.from, feeTo, fee);                                            // 5
        _transfer(t.from, t.to, t.value);
        if (t.entryRef != 0) emit PaymentSettled(t.from, t.to, t.value, fee, feeTo, t.entryRef);
        emit MetaTransactionExecuted(t.from, msg.sender, t.batch, t.nonce, digest, feeTo, fee); // 6
    }

    /// @dev Step 3: payee, fee on `value` (capped, CTR-MTX-13), the payee check (CTR-MTX-08), balance.
    function _checkTransfer(MetaTxLib.MetaTransfer memory t) private view returns (uint256 fee, address feeTo) {
        if (t.to == address(0)) revert PayToZero();
        if (t.to == address(this)) revert TransferToSelf();
        FeeMode fm = MetaTxLib.feeModeOf(t.mode);
        feeTo = t.feeRecipient == address(0) ? msg.sender : t.feeRecipient;
        fee = FeePolicy.compute(fm, t.value, t.fee);
        FeePolicy.validateRecipient(fm, feeTo);
        if (fee != 0) {
            if (feeTo == t.to) revert FeeRecipientIsPayee();
            if (feeTo == address(this)) revert TransferToSelf();
        }
        uint256 need = t.value + fee;
        uint256 have = balanceOf(t.from);
        if (have < need) revert MetaTxInsufficientForFee(need, have);
    }

    // ------------------------------------------------------------------ fee of a self-call (CTR-MTX-20)

    /// @notice After the call: `ABSOLUTE` = the signed amount, uncapped (step 3 refused `PERCENT`); `AMOUNT(i)` =
    ///         `FeePolicy.compute` on the basis (≤ 1 %). A failing transfer reverts the call too.
    function _chargeFee(address from, uint256 basis, MetaTxLib.MetaTransaction memory m)
        internal override returns (uint256 fee)
    {
        FeeMode fm = MetaTxLib.feeModeOf(m.mode);
        if (fm == FeeMode.NONE) return 0;
        fee = _mtxRule(bytes4(m.data)).feeClass == FEE_CLASS_ABSOLUTE ? m.fee : FeePolicy.compute(fm, basis, m.fee);
        address feeTo = _feeRecipientOf(m);
        FeePolicy.validateRecipient(fm, feeTo);
        if (fee != 0) _transfer(from, feeTo, fee);
    }

    // ------------------------------------------------------------------ allowance (CTR-TOK-01)

    /// @notice Caller and spender must both be contracts: no EOA grants or holds an allowance.
    function approve(address spender, uint256 value) public virtual override(ERC20, IERC20) returns (bool) {
        address caller = _msgSender();
        if (!SigCheck.isContract(caller)) revert CallerNotContract(caller);
        if (!SigCheck.isContract(spender)) revert SpenderNotContract(spender);
        return super.approve(spender, value);
    }

    /// @notice Only a contract spends an allowance; checked before the allowance.
    function transferFrom(address from, address to, uint256 value)
        public virtual override(ERC20, IERC20) returns (bool)
    {
        address caller = _msgSender();
        if (!SigCheck.isContract(caller)) revert CallerNotContract(caller);
        return super.transferFrom(from, to, value);
    }

    // ------------------------------------------------------------------ internals

    /// @dev Tokens parked at the token's own address are what a spoofed self-call would spend (CTR-MTX-18).
    function _update(address from, address to, uint256 value) internal virtual override {
        if (to == address(this)) revert TransferToSelf();
        super._update(from, to, value);
    }

    function _isContract(address a) internal view returns (bool) {
        return SigCheck.isContract(a);
    }

    function _msgSender() internal view virtual override(Context, MetaTxBase) returns (address) {
        return MetaTxBase._msgSender();
    }
}
```

```solidity
pragma solidity ^0.8.24;

import {ERC20MetaTx} from "./ERC20MetaTx.sol";
import {IMetaTokenV2} from "./IMetaTokenV2.sol";
import {IFactoryTokenV2} from "../factory/IFactoryTokenV2.sol";
import {IOpenFactoryV2} from "../common/IOpenFactoryV2.sol";
import {MetaTxLib} from "../common/MetaTxLib.sol";
import {FeePolicy, FeeMode} from "../common/FeePolicy.sol";

/// @title Common root of the v2 tiers on `ERC20MetaTx` (TW2 §3.3, §7; CTR-MTX-07). EIP-1167 clones.
/// @notice The named functions (CTR-MTX-09) only build the struct of their kind and run its pipeline. Transitional: features, roles, `PayLib` and provenance land in P1c.
///
///         No owner, no pause, no upgrade. The two init-time exceptions (R142) live in the wrapper tiers: the rate
///         admin (only when `adjustable`) and the guardian (only `disableWrap`).
abstract contract MetaTokenBase is ERC20MetaTx, IMetaTokenV2, IFactoryTokenV2 {
    using MetaTxLib for MetaTxLib.MetaTransfer;

    address public immutable FACTORY;
    address private immutable _SELF;
    /// @notice SmartKeyAccount implementation of this chain (built: `SubjectAccount`, renamed in P4; 0 = none). Only its EIP-1167 clones get 400k gas for
    ///         ERC-1271; every other contract wallet 50k.
    address public immutable SMART_KEY_ACCOUNT_IMPL;
    bytes32 private immutable _SMART_KEY_CLONE_CODEHASH;

    // one slot: creator ‖ version ‖ _tokenDecimals ‖ _initialized ‖ _legCount
    address public creator;
    uint64 public version;
    uint8 private _tokenDecimals;
    bool private _initialized;
    /// @dev Number of underlying legs (0 on tier 1); here so it shares the init slot.
    uint8 internal _legCount;
    string private _tokenName;
    string private _tokenSymbol;

    error NotFactory();
    error AlreadyInitialized();
    error MtxModeShape(uint32 mode);
    /// @notice Wrong underlying count for the tier (0 / 1 / 2–8).
    error UnderlyingCountInvalid(uint256 n);

    /// @dev Runs ONCE on the implementation and locks it, so nobody can `initialize` it.
    constructor(address factory_, address smartKeyAccountImpl_, bytes32 chainUid_) ERC20MetaTx(chainUid_) {
        FACTORY = factory_;
        _SELF = address(this);
        SMART_KEY_ACCOUNT_IMPL = smartKeyAccountImpl_;
        _SMART_KEY_CLONE_CODEHASH = smartKeyAccountImpl_ == address(0) ? bytes32(0) : keccak256(abi.encodePacked(
            hex"363d3d373d3d3d363d73", smartKeyAccountImpl_, hex"5af43d82803e903d91602b57fd5bf3"));
        _initialized = true;
    }

    /// @notice The factory calls it in the SAME call as CREATE2. `initData` per tier (TW2 §4, §5.1, §8.1).
    function initialize(address creator_, address[] calldata underlyings, uint64 version_, bytes calldata initData)
        external
    {
        if (msg.sender != FACTORY) revert NotFactory();
        if (_initialized) revert AlreadyInitialized();
        _initialized = true;
        creator = creator_;
        version = version_;
        _init(creator_, underlyings, initData);
    }

    /// @dev The tier decodes `initData`, calls `_setMetadata`, checks `underlyings`.
    function _init(address creator_, address[] calldata underlyings, bytes calldata initData) internal virtual;

    function _setMetadata(string memory n, string memory s, uint8 d) internal {
        _tokenName = n;
        _tokenSymbol = s;
        _tokenDecimals = d;
    }

    function tokenKind() external pure virtual returns (IOpenFactoryV2.TokenKind);

    function name() public view override returns (string memory) { return _tokenName; }
    function symbol() public view override returns (string memory) { return _tokenSymbol; }
    function decimals() public view override returns (uint8) { return _tokenDecimals; }

    function factory() external view returns (address) { return FACTORY; }
    function implementation() external view returns (address) { return _SELF; }

    function payLane(bytes32 payId) public pure returns (uint256) {
        return uint256(keccak256(abi.encodePacked("scaas.pay.lane", payId)));
    }

    // ------------------------------------------------------------------ named functions (CTR-MTX-09)

    function mtxTransfer(
        address from, address to, uint256 amount, uint256 batch, uint256 nonce, uint256 validUntil,
        uint32 mode, address relayer, bytes calldata signature
    ) external nonReentrant returns (bool) {
        if (mode & ~MetaTxLib.MODE_RESTRICT_RELAYER != 0) revert MtxModeShape(mode);
        MetaTxLib.MetaTransfer memory t;
        t.from = from;
        t.to = to;
        t.value = amount;
        t.batch = batch;
        t.nonce = nonce;
        t.validUntil = validUntil;
        t.mode = mode;
        t.relayer = relayer;
        _executeTransfer(t, signature);
        return true;
    }

    function mtxTransferWithFee(
        address from, address to, uint256 amount, uint256 batch, uint256 nonce, uint256 validUntil,
        uint32 mode, address relayer, uint256 fee, address feeRecipient, bytes calldata signature
    ) external nonReentrant returns (bool) {
        _requireFeeShape(mode, feeRecipient);
        MetaTxLib.MetaTransfer memory t;
        t.from = from;
        t.to = to;
        t.value = amount;
        t.batch = batch;
        t.nonce = nonce;
        t.validUntil = validUntil;
        t.mode = mode;
        t.relayer = relayer;
        t.fee = fee;
        t.feeRecipient = feeRecipient;
        _executeTransfer(t, signature);
        return true;
    }

    /// @notice `mtxExecute` that says "this intent pays a fee": fee nibble ≠ `NONE`.
    function mtxExecuteWithFee(MetaTxLib.MetaTransaction calldata m, bytes calldata signature)
        external nonReentrant returns (bytes memory)
    {
        if (m.mode & MetaTxLib.MODE_FEE_MASK == 0) revert MtxModeShape(m.mode);
        return _execute(m, signature);
    }

    /// @notice Payment `payId` on its own lane `payLane(payId)`, nonce 0 (CTR-MTX-10).
    function mtxPay(
        address from, address to, uint256 amount, bytes32 payId, uint256 validUntil,
        uint32 mode, address relayer, uint256 fee, address feeRecipient, bytes calldata signature
    ) external nonReentrant returns (bool) {
        MetaTxLib.MetaTransfer memory t;
        t.from = from;
        t.to = to;
        t.value = amount;
        t.entryRef = payId;
        t.batch = payLane(payId);
        t.validUntil = validUntil;
        t.mode = mode;
        t.relayer = relayer;
        t.fee = fee;
        t.feeRecipient = feeRecipient;
        _executeTransfer(t, signature);
        return true;
    }

    /// @dev Fee `PERCENT`/`FIXED`, recipient bound by the signer and non-zero.
    function _requireFeeShape(uint32 mode, address feeRecipient) private pure {
        uint32 f = mode & MetaTxLib.MODE_FEE_MASK;
        if ((f != MetaTxLib.MODE_FEE_PERCENT && f != MetaTxLib.MODE_FEE_FIXED)
            || mode & MetaTxLib.MODE_RESTRICT_FEE_RECIPIENT == 0 || feeRecipient == address(0)) {
            revert MtxModeShape(mode);
        }
    }

    // ------------------------------------------------------------------ direct path

    /// @notice The caller pays gas itself; the fee is on top, `amount` arrives whole; never to the payee (CTR-MTX-08).
    function payWithFee(
        address to, uint256 amount, FeeMode feeMode, uint256 fee, address feeRecipient, bytes32 entryRef
    ) external returns (bool) {
        address payer = _msgSender();
        uint256 feeAmount = FeePolicy.compute(feeMode, amount, fee);
        FeePolicy.validateRecipient(feeMode, feeRecipient);
        if (feeAmount != 0) {
            if (feeRecipient == to) revert FeeRecipientIsPayee();
            _transfer(payer, feeRecipient, feeAmount);
        }
        _transfer(payer, to, amount);
        emit PaymentSettled(payer, to, amount, feeAmount, feeRecipient, entryRef);
        return true;
    }

    function _erc1271Gas(address from) internal view override returns (uint256) {
        bytes32 h = _SMART_KEY_CLONE_CODEHASH;
        return h != bytes32(0) && from.codehash == h ? 400_000 : 50_000;
    }
}
```

```solidity
    function receiverFeeDigest(bytes32 paymentDigest, uint256 fee, address feeRecipient, uint256 validUntil)
        public view returns (bytes32)
    {
        return _hashTypedDataV4(keccak256(abi.encode(RECEIVER_FEE_TYPEHASH, paymentDigest, fee, feeRecipient, validUntil)));
    }

    /// @notice The payer's payment runs untouched; then the payee, who co-signed `ReceiverFee` over the payer's
    ///         digest, pays `fee` to `feeRecipient` in the same transaction.
    function mtxPayReceiverFee(
        MetaTxLib.MetaTransfer calldata t, bytes calldata payerSig,
        uint256 fee, address feeRecipient, uint256 rfValidUntil, bytes calldata payeeSig
    ) external nonReentrant returns (bool) {
        if (t.entryRef == 0 || t.mode & MetaTxLib.MODE_FEE_MASK != 0 || t.fee != 0
            || t.mode & MetaTxLib.MODE_RESTRICT_RELAYER == 0 || t.batch != payLane(t.entryRef) || t.nonce != 0
            || feeRecipient == address(0)) revert ReceiverFeeShape();
        if (block.timestamp > rfValidUntil) revert ReceiverFeeExpired(rfValidUntil, block.timestamp);
        if (fee == 0 || fee > t.value) revert ReceiverFeeAmount(fee, t.value);
        if (feeRecipient == t.to) revert FeeRecipientIsPayee();
        bytes32 d = _executeTransfer(t, payerSig);
        _requireValidSignature(t.to, receiverFeeDigest(d, fee, feeRecipient, rfValidUntil), payeeSig);
        _transfer(t.to, feeRecipient, fee);
        emit ReceiverFeePaid(d, t.to, feeRecipient, fee);
        return true;
    }
```

```solidity
/// CTR-MTX-18: authority and balance owners are read through `_msgSender()`; the reads that stay `msg.sender`
/// are exactly: the reentrancy guard and `_msgSender()` itself, the relayer binding, the default fee recipient and
/// the event `relayer` (both pipelines), and the factory check in `initialize`. Comment lines are skipped. A change
/// here is deliberate: update the pin in the same commit and say why.
contract MsgSenderLintTest is Test {
    function _count(string memory path) internal view returns (uint256 n) {
        bytes memory s = bytes(vm.readFile(path));
        bytes memory pat = bytes("msg.sender");
        bool lineStart = true;
        bool comment;
        for (uint256 i; i < s.length; ++i) {
            bytes1 c = s[i];
            if (c == "\n") { lineStart = true; comment = false; continue; }
            if (lineStart) {
                if (c == " " || c == "\t") continue;
                lineStart = false;
                comment = c == "/" && i + 1 < s.length && s[i + 1] == "/";
            }
            if (comment || i + pat.length > s.length) continue;
            bool hit = true;
            for (uint256 j; j < pat.length; ++j) {
                if (s[i + j] != pat[j]) { hit = false; break; }
            }
            if (hit) ++n;
        }
    }
```
